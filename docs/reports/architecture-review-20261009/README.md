# CPQ Agent 架构与决策复盘（2026-10-09）

这套文档是对 `cpq_agent` 全仓的一次**自顶向下复盘**：每个模块写清「产品上是什么」「技术上怎么实现」「关键决策与原因」「已知缺口」，最后给出**可优化项**供拍板。

写作口径：

- 只写仓库里能查证的事实，不写推测性结论；无法验证的一律标注「未验收」。
- 产品侧用业务语言，技术侧给出文件、函数、接口与数据形状。
- 优化项一律标注 **收益 / 代价 / 风险 / 我的建议**，由你拍板；本文档不代表已授权实施。
- 本文档是**只读分析产物**，不改动任何业务代码、测试或线上数据。
