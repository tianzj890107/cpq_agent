## 实际工艺推荐：严重错误

选用酒盒底板面纸实际运行 `process.outline_process`：本地 HTTP DA 桥返回 unavailable，得到“毛坯准备→建立基准并加工主体→去毛刺与清理→最终检验”。

为排除桥接配置因素，再用**进程内只读适配器**连接真实 PG，未伪造路线、未改生产配置、未冒充线上HTTP通过。`for_row` 实际查到本件路线及真实行：开料→UV印刷→覆哑膜→丝印UV→浮雕击凸→模切→包盒。将这一载荷按生产代码方式写入 grounding，再运行同一工艺推荐；结果仍是上述四道通用机械步骤。

所以不仅是“有没有匹配上”：匹配后的路线只是提示词参考，实际包装工艺输出仍可能失真。代码中 `process.py` 的系统提示、`_base_route` / `ensure_minimum_route` 仍有机械加工/去毛刺默认口径；业务件适配 `business_as_ir_part` 输出 role=None、features=[]。这些是明确需进一步修复的接线点，不能仅靠相似度解决。

第一次诊断打印包含 OpenQuestion 对象时 JSON 序列化失败，属于本轮诊断输出格式问题，不是生产工艺接口错误；随后改用 plan.model_dump，成功取得并验证上述实际步骤。

## 必须补的实现

1. 圆盘各组成的尺寸证据与材料归属接入实际下游输入，不能仅在预览显示 bbox；保持不按答案硬编码。
2. 包装专用工艺生成/降级：原库工序作为受约束候选，保留来源；不得默认补机械加工与去毛刺。无有效输出应明确缺口，不产出看似完整的错误路线。
3. 正确向工艺生成传递包装行业、物理组成与路线依据；匹配结果不能仅藏在一段 note 中。
4. 原材料单价、税因子、灰板/复合材料适用计价路径及加工工时/费率补齐，缺失保持缺口，不能取相似件价格充当本件标准。
5. 真实各件工艺→完整 BOM→确认项目路线→项目公式成本再验收。本轮尚未闭环。
