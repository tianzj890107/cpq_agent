# 包装排版排模与新增组装工艺验收

日期：2026-10-13。本地实现与隔离测试；未提交、推送、部署，未修改线上项目或数据库。

## 交付

- 包装第3阶段只有3.1排版排模、3.2组装工艺；内部params/process地址不变，旧drawings地址归入排模。其它行业保留原步骤。
- 方案选择并入排模；关联零件复选框固定14px，数字输入紧凑、长名称可换行、展开列表限高。关联保存与折叠入口保持同一行。
- 新增组装方案只保存跨完整零件的组装/检验工序，每道工序至少绑定两个有效整件编码。新增按钮可调整并实际保存关联，用户气泡先于保存及Agent回复。
- 已有单件制造工艺不删、不复制到组装页；完整路线仍由制造工序和新增组装工序组成。关联数量不被当作用量，新增工序每套只计费一次。
- 新增方案单次模型调用；相同输入可复用，零件、方案或制造工艺变化失效。模型不可用时沿用估算降级，明确来源，不伪装AI成功。
- 工艺投影读取实际制造记录；首页卡片、步骤导航、工作区统一包装的两步编号。
- 修改新增组装工序或关联后，旧路线/成本标记过期，需沿原入口重算。
