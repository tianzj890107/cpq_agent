# 多方案解析与工艺入口本地验收

日期：2026-10-12。未提交、未推送、未部署、未写任何线上项目；保留其他任务的未提交修改。

## 实现

- 工艺批量按钮遍历业务零件，按钮可用态也读业务清单，不再把几百个几何分量传给工艺目标判定。
- 整张图多个方案可解析；标题和图纸空间间隔给出带证据的作用域，上下/左右均支持。不写固定坐标、件数或 BOM 答案。
- 同名不同方案保留不同业务编号。每条零件及排模带方案标识，前端零件行显示方案，采用方案按钮沿用 `part-row-action`，排模关联选项限制在本方案或公共件。后台也拒绝跨方案关联。
- 纯排模方案不复制业务件集合。内托方案分别解析，未明确范围的图形保留原图与诊断，不擅自当公共件。
- 选择采用方案带业务版本 hash 校验、角色校验和操作来源；仍保存两套完整清单，选定方案及公共件才参与整单 BOM、路线与成本。切换会改变业务文档版本，使旧结论按既有版本口径失效。
- 未采用方案的成本读取返回业务 409 提示，不抛未处理异常。未选方案不能汇总两个方案。
- 业务解析器失败时零件步骤报受阻，不再把“几何已拆完”标为“业务零件已完成”；几何进度文案明确称“区域”。
- 发现整图大闭合框使圆件被当内孔：方案内排除包含多个方案标题的外框、重新构建局部分组，保留原始实体及原有分量身份，对新增分量加方案命名空间。
