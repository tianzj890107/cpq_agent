# Agent 输入区不显示常驻文件能力说明

## 范围与验收

- 报价、技术工艺共用的文件策略脚本不得在对话输入区创建常驻的文件能力说明，包括文件大小、直接解析/转换/仅保存用途说明。
- 静态与动态文件控件仍应用同一用途白名单、16 MiB 大小限制、空文件校验和错误反馈；不修改后端能力、不放宽上传限制。
- 文件控件自身的悬停说明保留；不改变消息、附件保存及交接。
- 实际 Chrome 检查输入区没有 `filePolicySummary`，且动态控件的用途过滤仍生效。

34 服务健康接口返回 200。现有日志记录需求识别使用 deepseek-v4-flash，等待 253.98 秒后报 incomplete chunked read。另有工作流消息读取的 PG 连接超时；日志不能证明两者同一时刻发生。健康检查成功不等于模型或数据库依赖始终可用。
