# 成本回传任务上下文修复

2026-10-20 紧急修复，用户授权验证后双远端推送并部署34。不得改同事项目、领取人或代其回传。

## 原因与契约

工艺来源任务用于找回原销售报价，成本任务用于结束报价人员待办。成本页沿用工作台URL中的通用task_id，不能把前者当作后者关闭。

1. 成本回传销售、提交工艺经理两个出口共用任务解析：若入参为空或恰好等于本项目需求/元数据中明确记录的工艺来源任务，使用本项目已保存 `finance_handoff.task_id`。显式传入的其他任务号不悄悄替换，仍由既有服务端归属校验裁决。
2. 已知工艺来源任务却没有成本交接记录时，在发交接之前返回清楚的409，引导从本人已领取的成本待办进入；不能关闭工艺任务，也不自动创建/领取/转派成本任务。
3. 真实成本任务仍校验项目、类型、领取人、状态；他人已领取、跨项目、未领取均不得绕过。原报价定位仍使用原工艺来源任务，不改销售会话、金额、成本版本或报价步骤。
4. 兼容旧页面，无需依赖刷新后才纠正错误task_id；非成本出口与原始工艺回传不改。无任务上下文的既有旧流程维持兼容。
5. 重试保持原有原子事务和幂等，不重复建任务、不修改历史业务数据。

## 验收

红测覆盖实际混用的两类任务、两个出口、未携带/显式正确/未知任务、无成本任务保护，以及真实受控事务中只关闭报价人员任务、保留工艺经理任务。部署后仅只读验证同事项目解析到正确任务及权限保护，不替用户点击回传。
