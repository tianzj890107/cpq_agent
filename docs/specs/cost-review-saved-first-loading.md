# 成本页：已存成本先显示，核验与公式详情分开读取

## 目标

刷新/进入4.1–4.3时先显示已经保存的成本，不等待工艺/BOM/规则版本核验、会话回放或模型配置。只读刷新不重新测算，不修改业务数据，不更改金额口径。

## 契约

1. 成本GET增加`saved`轻量视图：包装项目只读现存需求、业务件目录、成本账头和明细及评审记录；不得读取当前工艺/BOM/知识库或执行公式。使用现有账本归集方法，金额与完整视图同源。未测算清晰返回未测算，不把读取失败当零元。非包装沿用完整路径。
2. saved显式`verification_pending=true`、`ready=false`。首屏保留历史确认信息，但不能确认、写库、回传或测算覆盖；待完整核验完成恢复原业务门禁。后端所有写接口继续走原权威核验。
3. `summary`视图执行原完整核验，但不生成/传输每件公式详情和重复原始明细。原默认GET保持兼容。
4. 计算详情点击后加载，必须检查当前账本版本，版本已变化返回409，不把另一版依据贴到旧金额上；关闭/切换弹窗后迟到响应不能更新新弹窗。失败提供重试。
5. 前台刷新采用请求序号及AbortController，旧响应不得覆盖新响应；背景失败保留已显示金额并显示可重试提示，不冒充核验成功。切换页签保持用户当前选择，后台回包不重置输入框。
6. 会话、模型名称并行恢复，不阻塞成本；历史入口读取saved而非提前请求整套成本核验。
7. 不持久化新的权威金额，不新增公式、不改ACL、不自动计算、不自动切阶段、不清空会话。
8. 财务读权限中“已有包装成本”的判断只查询成本账头是否存在，不得先调用完整成本核验。角色、项目关联与归档规则不变；存储错误仍失败关闭。既有权限测试可调整读取桩到新轻量入口，权限断言不变。

## 验收

- 注入会抛错的当前路线/BOM/规则服务，saved仍能读出既有金额；出错的存储不能被吞成空数据。
- summary与full逐项金额、数量、状态一致；summary没有公式详情和重复items。
- 真实成本临时库验证saved不写、缺账与版本冲突。
- 延迟核验仍先render(saved)，失败保留表格，重试恢复；交错回包不倒灌。
- 真实浏览器确认首屏可见、待核验动作禁用、详情按需及弹窗迟到隔离；保留现有风格。
