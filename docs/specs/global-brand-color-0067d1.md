# CPQ 全局品牌色统一为 #0067D1 Spec

状态：TDD Red，等待 DeepSeek 实现。

## 结论

`#0067D1` 是饱和度较高的中深蓝色。本需求将其设为 CPQ 全产品唯一品牌主色，消除现有页面中紫色、紫蓝渐变和多套品牌蓝并存的问题。

## 颜色系统

一方前端必须统一使用以下品牌色阶：

| 用途 | 色值 |
| --- | --- |
| 主色 / 默认操作 | `#0067D1` |
| 悬停 | `#0057B8` |
| 按下 / 深色强调 | `#004A9F` |
| 浅背景 / 选中底色 | `#EAF3FC` |
| 更浅页面染色 | `#F4F9FE` |
| 浅边框 | `#B8D7F4` |
| 半透明焦点、阴影 | `rgba(0, 103, 209, <alpha>)` |

旧变量名如 `--color-purple`、`--color-secondary` 因兼容性必须暂留时，也必须解析为上述蓝色色阶；新代码不得继续把紫色作为品牌色。品牌渐变应取消为纯色，或仅在用户明确要求保留层次时使用 `#0067D1 → #0057B8` 的同色系蓝色渐变，不得混入紫色。

## 覆盖范围

“全局”包括仓库内所有一方用户界面，而不是只修改当前首页：

- 报价助手：首页、工作台、报价规则、认证、消息、设置、历史；
- 配置助手：首页、配置 BOM 工作台及公共导航；
- 规则助手：首页、规则配置工作台及公共导航；
- 技术工艺：首页兼容入口、统一双栏工作台、会话、需求、图纸解析、工艺、成本、汇总、审核、发布、账户与登录；
- `tech_app/apps/tech-process/` 内的一方覆盖样式和行内品牌色。

第三方依赖、vendor 文件、图片像素、用户上传文件、历史业务数据和后端返回内容不在机械替换范围内。

## 组件映射

以下非语义组件必须统一到品牌色阶：

- Logo、品牌图标、标题高亮；
- 主按钮、发送按钮、创建按钮及 hover/active/focus；
- 当前助手、当前导航、当前步骤、Tab 下划线、分页选中态；
- 普通链接、可点击图标、复选/单选选中态；
- 输入框焦点边框和 focus ring；
- 信息型 badge、进度条、步骤圆点；
- 卡片选中/悬停边框、品牌阴影；
- 页面紫蓝背景渐变，改为同色系浅蓝背景，不得保留紫色端点；
- JS 动态注入 CSS、运行时 style 和图标颜色。

## 必须保留的语义色

不得把所有颜色盲目替换成蓝色。以下状态继续使用现有语义色：

- 成功、完成、通过：绿色；
- 警告、待处理：黄色或橙色；
- 错误、失败、拒绝、删除、危险操作、未读红点：红色；
- 正文、次要文本、禁用态、边框：既有中性色；
- 数据图表确需区分类别时可以保留多色，但品牌主系列和默认系列必须使用 `#0067D1`。

颜色判断必须结合选择器、变量用途和组件语义，禁止对所有十六进制色值做无差别批量替换。

## 工程约束

- 优先在每个独立页面/应用的主题变量入口定义统一 token，再消除绕过 token 的硬编码品牌色。
- 公共组件 `cpq_auth.js`、`cpq_msg.js` 等的 fallback 也必须改为 `#0067D1`，否则缺少宿主变量时会恢复旧色。
- CSS、HTML 行内样式和 JS 字符串生成的样式均需扫描。
- 色值比较不区分大小写，但实现建议统一大写六位十六进制格式。
- 不引入新的 UI 框架，不重写页面结构，不改变业务行为。
- 不修改第三方 vendor 资产，不修改 SVG 中具有业务含义而非品牌含义的原始图纸颜色。

## 非目标与安全边界

- 不修改 API、数据库、权限、公式、流程和路由语义。
- 不删除历史项目、会话、任务、附件、设置或业务数据。
- 不以全局蓝色覆盖成功、警告、错误和危险操作。
- 本需求不授权 push、MR、tag、Release、部署、服务重启或浏览器操作。

## 验收标准

1. 四个助手首页、工作台与技术工艺九阶段的所有品牌主色均为 `#0067D1`。
2. 不再出现紫色品牌变量、紫蓝渐变及旧品牌色 `#6366F1`、`#8B5CF6`、`#7C3AED`。
3. 旧的多套品牌蓝统一，不再以 `#3B82F6`、`#2563EB`、`#1D4ED8`、`#1677FF`、`#2F6BFF` 作为主操作色。
4. hover、pressed、浅背景、浅边框、focus ring 和阴影均使用约定的同色系蓝色阶。
5. 登录和消息等动态注入组件在有无宿主主题变量时都使用新主色。
6. 成功绿、警告橙、错误/删除红仍能清楚区分，没有被改为蓝色。
7. 页面布局、业务交互、技术工作台路由和已有数据行为不变。
8. 新增 Red 测试转绿，已有测试保持通过。
