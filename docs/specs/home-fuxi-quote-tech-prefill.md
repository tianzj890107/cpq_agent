- 首次进入 quote / tech 时，输入框 `value` 填入对应正文，而非只改变 placeholder。
- 点击另一个助手 tab 时，用目标正文替换输入框当前内容，随后仍可编辑；再次点击当前 tab 不覆盖用户编辑。

- 隐藏只作用于首页入口，不删除历史或禁用已有独立页面。旧 config / rule URL 的兼容策略沿用现有行为，本批不扩展。
