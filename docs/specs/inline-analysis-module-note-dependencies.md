# 单件工艺与成本面板的模块依赖

## 缺陷
app.js 是 ES module，inline-analysis.js 是普通脚本。后者直接调用前者的顶层函数，导致成功读取结论后抛 ReferenceError，被误显示为读取失败。

## 验收
- 模块通过明确的 PackagingConclusionNotes 接口共享业务身份、尺寸依据格式化函数；普通脚本不得假定模块函数是全局变量。
- 工艺、成本的 GET 读回以及生成结果读回均使用该接口，显示已有结果，不额外提交生成任务。
- 保留业务清单版本漂移、权威尺寸来源与几何绑定提示。
- 接口未初始化时明确提示页面组件未就绪，不伪造空结论或吞掉来源信息。
- 回归在独立脚本作用域运行真实 load 函数，覆盖工艺和成本；不能仅检查函数名是否存在。
