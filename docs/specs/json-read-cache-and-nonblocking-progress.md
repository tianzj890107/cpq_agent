# 大文档读取性能与进度

文件后端按路径+inode+mtime_ns+size缓存JSON解析结果，缓存有条目数及源文件字节预算；每次读验证文件签名，原子替换/外部修改后不得返回旧版。返回独立副本，不允许调用方修改污染缓存。损坏JSON仍报错，不用旧缓存掩盖错误。

get_meta/get_doc/list_metas/list_audit不得持有全后端写锁执行文件读取或副本构造；原有写与审计读改写锁保留。读可看到原子替换前或后的完整版本，不得半份文档。

业务单件工艺读取复用一次加载的当前业务文档；历史按需比较，不读取与该业务结论无关的大几何文档。批量生成等待已有工艺时显示running/正在读取，不冒称模型排队；请求有超时并保留已有工艺，不能把读失败当无结果覆盖。

验收包含缓存命中、外部失效、副本隔离、全局锁不阻塞读、缓存预算、真实损坏报错及前端超时语法；部署后只读测量，不重解析、不代点工艺任务、不删除项目或改候选。
