# 包装相似件工艺借鉴与前端闭环

## 目标与边界
同件匹配读取数据库原工序；相似件不是同件，必须由模型按当前件调整，不复制尺寸、价格、标准工时或批准状态。外购件短路。数据库只读，不写生产数据。不以酒盒或圆盘件数、答案尺寸编写专用规则。

## 检索与生成
保留身份匹配的方向、编号、件型约束。新增独立工艺借鉴检索，允许内外/左右/编号不同的同材料件作参考；已知材料类型冲突仍排除。基于名称、材料、已核实尺寸排序，最多三条参考，明确这不是概率或同件确认。每条必须读取真实路线头和工序行；无工序的候选不冒充参考。

模型输入包括当前件材料、尺寸证据和需求说明、参考件及原工序。提示必须区分印刷/覆膜/开槽等是否适用：证据不足列问题，不能照搬 UV、击凸。当前接口未给出的形状/厚度/印刷要求不推造。近分参考可同时提供模型，但身份歧义不得自动选成同件。

相似命中走模型调整；名称或编码精确命中保持原顺序与重复工序。模型为空/失败明确报错，不退回机械模板或直接复制参考。AI 结果未批准，未知工时留空；借鉴引用不作为已复用标准工序。桥不可用区别于无参考，不声称空库。

## 前端
单件和组成共用后端链路。既有工艺详情必须显示中文来源、参考件名称与编码、推荐依据、待补问题，不直接输出 JSON/内部枚举；刷新已保存结果也显示。沿用现有行、表格、详情和紧凑按钮样式，禁止新增巨型按钮、字体、页外跳转或原始技术字段。来源可展开，不新增重复聊天卡片。

## 验收
自动化覆盖精确保序、相似调用模型且模型可删除不适用工序、无命中参考头行进入模型、未知工时不继承、外购拒绝、模型空输出失败及前端渲染。相关旧回归必须运行；测试红点与后续绿点分别记录。不宣称线上或全部解析尺寸正确。

## 本轮实现与验证（2026-10-10）
首轮3项实际失败（2失败1错误）；扩展8项全部通过。相关模块119项通过（该轮包含新增测试扩展前的3项）；前端 JS 语法与 diff 空白检查通过。前端测试本轮是静态接线断言，不等于浏览器视觉验收。未启动服务、未调用真实模型、未部署。形状等当前件字段依赖调用方现有证据说明；本轮未新增图形识别算法或保证尺寸准确。模型提供工序建议，仍需工程核对，无法保证每道工序自动正确。
