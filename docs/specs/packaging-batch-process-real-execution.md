# 包装一键工艺推荐真实执行

一键工艺必须串行POST业务零件process接口并轮询真实任务，不得以打开面板代替生成。有效既有结果可跳过，过期结果重算；外购件明确跳过，失败逐件保留原因、继续剩余件。只读失败不得当作无结果直接覆盖。切换项目停止提交后续件，不将结果写到新项目。

按钮动作必须提供prompt与唯一runId，先用户气泡再Agent执行卡；排队、逐件过程、失败和终态均通过既有桥与会话持久化链路。单件内嵌生成同样带prompt/runId，提交失败也必须有失败气泡。读旧工艺不等于生成，不触发模型；过期工艺允许只读展开、不可冒充当前有效。

本轮仅本地修复；部署和线上生成任务需要当前明确授权。禁止伪造工艺推荐结果或绕过角色门禁。
