# 包装 CAD 候选默认选中即自动确认归属

状态：Spec + 红测（已实现）。覆盖 `packaging-candidate-confidence-default-selection-20260929.md` 中“预选不写入”的旧口径；置信度展示与排序继续保留。
红测：`tests/test_packaging_candidate_auto_binding_red.py`

## 目标

图纸推导业务部件有多个候选时，系统自动将最高置信度且可由现存 CAD 图元完整支持的候选绑定为该件的归属，无须点击“确认当前候选归属”。用户从下拉切换到其他候选，即视为选择该归属并立即保存；不再出现第二次确认按钮。

## 边界

1. 自动归属发生在解析产物落库前；已有图纸推导文档在有写权限的用户打开 2.1 时可幂等补归属。系统按服务端从候选本身重算的证据分排序，不能信任浏览器传来的分数或候选实体列表；同分按候选 ID/原序稳定决胜。
2. 候选必须真实存在于该项目的候选队列，带可追溯实体、完整的已保留 CAD 分量；实体集合与分量集合一致，且未被另一业务件占用。最高分候选不满足这些条件时保持待确认并说明原因，不擅自改选第二名。无候选、0 分、部分几何、共享实体均不自动绑。
3. 自动绑定记 `bound_by=auto`、候选 ID、证据分和规则版本，归属状态与人工绑定明确区分；不得伪造 `human_confirmed`、操作者或 `size_confirmed`。已有人工绑定、已确认尺寸及非图纸来源文档保持原样。重复运行不产生新版本或重复审计。
4. 用户改选直接调用现有几何绑定接口，成功后读回并刷新图纸；失败保留原绑定、显示原因。改选属于用户操作，记录真实操作者与候选 ID。改选不同图元会把旧确认尺寸移入历史，当前尺寸重新待核。默认自动绑定不取代尺寸确认：BOM、单件工艺、成本仍需核对并确认长宽。
5. 已绑定自动候选在图纸里优先展示；候选列表保留以便改选。没有写权限的读者只能看结果，不因 GET 产生后台写入。

## 验收

- 新解析的 8 候选中最高分且完整者自动成为 `bound`、`auto`；不需要人工按钮。
- 改选后立即写入、可读回，刷新页面仍是该归属；旧人工绑定不被自动覆盖。
- 最高分冲突、只有原始碎片、0 分或不存在实体时不自动确权；下游尺寸门禁不被绕过。
- 酒盒、圆盘盒不依赖金标、文件名、固定候选数或硬编码尺寸；通用工作簿和其他行业不变。
