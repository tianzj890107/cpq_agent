# 候选同分与串件连锁修复

状态：Spec + 红测（已实现）；仅本地，尚未部署。
红测：`tests/test_packaging_candidate_cascade_red.py`
验收记录：`docs/reports/packaging-candidate-cascade-acceptance-20261012.md`。

目标：复合候选不能仅凭同名附近的多个闭合分量跨视图区合并；显示分封顶不得抹掉真实证据排序；完整候选冲突时不得静默选择其局部子集。

单一件名没有明确多组成声明时，合并至少要求同一局部视图证据；不同视图只可由明确组成声明或其他独立结构证据支持，不因同一大图框就视为同件。合法多组成仍保留。

自动和前端排序用未封顶证据分，显示置信度仍封顶85%，不当概率。真实分同分再比较支持状态，最后才用稳定ID确保确定性。禁止业务编号、样图坐标、候选序号特例。

发生归属冲突后，不得回退到冲突完整候选的严格实体子集；其他独立且合法的完整备选仍可选。保留人工归属，不做全图重新分配。

红测：tests.test_packaging_candidate_cascade_red。酒盒验收使用线上候选上下文及实际DXF新解析；人工选择只在解析结束后对照。旧BP05不是正确金标，须单独对照用户指出的完整区域。此次不授权部署或生产历史改写。
