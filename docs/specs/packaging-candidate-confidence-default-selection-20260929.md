# 包装业务部件候选图形：置信度与默认预选

状态：Spec + 红测（已实现）；2026-09-30 归属规则已由 `packaging-candidate-auto-binding-20260930.md` 覆盖；本文件保留 9-29 的原始阶段记录，当前实现以新 Spec 为准。
红测：`tests/test_packaging_candidate_confidence_default_red.py`

## 现场缺口

一件业务部件最多展示 8 个 CAD 图形候选。下拉框目前只有候选编号和 ID，默认取模型建议或列表第一个；用户无法知道哪个证据更强。切到别件再回来也不保留刚才的人工预选。

## 规则

1. 每个候选显示 0–100% 的“置信度”。这是由已有 CAD 证据计算的**排序参考分**，不是经统计校准的正确概率，更不代表尺寸已确认；提示文案必须说明这一点。不得根据样本文件名、期望零件数、金标 BOM 或未见过的图片编分。
2. 评分输入只限候选已有的实体、分量、名称锚点是否落在范围内、图纸尺寸标注是否与候选空间对应、轮廓状态、锚点到候选距离与包围盒。每项权重固定，可复算；无效/缺失数值按无证据处理，结果限在 0–85%。没有任何实体或分量 ID、仅有包围盒的候选得 0 分。CAD 证据较强者分数较高；相同证据同分稳定按候选 ID/原顺序决胜。模型建议不单独抬高分数。
3. 未人工选择时，预览默认选中置信度最高者；下拉选项按分数降序，逐项显示百分比。人工改选后，同一项目、同一业务部件文档版本、同一业务件在页面会话内保持其选择；候选消失或文档版本变化时回退最高分。
4. “预选”只控制预览和待确认候选；不得调用绑定写接口、修改业务部件文档、将状态改为 `bound`、设置 `size_confirmed`、流入 BOM/工艺/成本。只有用户点击原有“确认当前候选归属”才发写请求；确认尺寸仍是独立动作。
5. 已有人工绑定的件继续优先画已绑定图形，候选排序不覆盖绑定。没有候选时不显示伪造的分数或选择器。

## 验收

- 8 个候选都带百分比，最高分预选；打乱服务端候选顺序不改变最高分选择。
- 人工选低分候选后切走再返回仍选它；候选删除后回到最高分。
- 选择操作不写后端，未确认状态及下游门禁不变。
- 既有图纸预览、图层颜色与手动确认入口保留。
