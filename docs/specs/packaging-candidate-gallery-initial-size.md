# 零件首屏尺寸、候选图集与适应窗口

2026-10-08。直接本地实现，不包含部署。

- 首次打开清单就显示已有尺寸：人工尺寸优先；已有组成的 CAD 标注尺寸直接读取（单组成也适用）；参考清单尺寸及已绑定几何尺寸继续兼容；只有候选时用既有最高分/已选候选的范围显示参考尺寸，不要求重新选一次。缺尺寸显示缺口，包围估算不得变成确认尺寸或用于绕过成本门禁。
- 候选下拉项附来源；下方可展开全部候选缩略图、证据来源、尺寸和排序分，可点击看大图。查看不保存，选用仍走原有权限/保存 API；未知来源如实标记，预览无坐标显示原因。多个候选是不同证据生成的备选组合，不是多个已确认零件。
- 当前图形及候选缩略图按真实实体绘制，保留图层颜色，不按邻件大包围框拼图。明确区分当前保存归属与仅预览的候选。
- 提示/工具条移出正方形 SVG 视口；100% 指适应当前图形的相对缩放，不是页面缩放。右栏有单一滚动容器；进入零件时回到顶端，不保留上件滚动到底的位置。包装视图取消 modelPanes 的 flex 撑满/底部挤压，不影响其他行业。
- 新需求允许缩略图集拥有多个 SVG，替代旧 Spec 中“右栏同时至多一个 SVG”的字面数量限制；仍只有一个可交互主图，缩略图不共享拖拽绑定。

## 实现记录

- 初始 4 项红测全部失败：单组成尺寸遗漏、未绑定候选首屏无参考尺寸、无来源图集、无布局/滚动修正。实现后补缩略图集实体范围/转义及画布外复位按钮执行测试，新增模块共 6 项通过。
- 相关 13 个模块 184 项通过；之后新增一项复位按钮测试，独立复跑新增模块 6 项通过（两组测试有重叠，不能相加）。前端模块语法和 `git diff --check` 通过。
- 主图预览不再被已绑定归属强制覆盖；预览状态有明确提示与“选用当前候选”动作。查看缩略图不发归属写请求，只是前端查看；只读角色也能查看。
- 原始候选全部保留，没有通过删候选掩盖识别歧义。尺寸显示优先已有人工/标注结果，候选范围仅作参考，不写回确认尺寸或放宽下游门禁。
