# 包装 DWG 多连通片尺寸与选件视口修正

## 问题与证据

酒盒 DWG 离线重跑时，「左盖面纸」「右盖面纸」分别被配到仅含三条图元的连通碎片，得到
218.197×68.246 和 113.0425×384.674 mm。两行 `size_confirmed=false`，却被作为整件尺寸上屏。
同图存在一组 307.0675×528.894 mm 的正交尺寸标注，矩形范围包含左侧四组几何分量；右侧
有至少三组分量与左侧满足同尺寸、同纵坐标的镜像对应。客户资料中的 BOM 只用于离线对答案，
解析运行时不得读取、匹配或回填 BOM。

## 规则

1. 普通最近连通分量匹配仍是默认路径。仅当一个 DWG 尺寸矩形内部有至少三个有效分量、
   分量并集对宽高两轴的覆盖率均达 90%、名称锚点位于其下方且原匹配尺寸未确认并明显小于
   整块范围时，才用整块标注范围替换碎片范围。记录多分量、图元、范围与
   `size_source=multi_region_dimension`，`size_confirmed=true`。
2. 左右同尾名仅是候选提示，不能凭名称复制尺寸。另一个部件必须有至少三个分量通过坐标镜像、
   逐件尺寸及纵坐标核对，且其名称锚点贴近对应整块范围，才继承该尺寸；记录
   `size_source=mirrored_multi_region_dimension`，`size_confirmed=false`，下游仍可识别其非直接标注证据。
3. 完整件图应绘制整块范围内所有实际 DWG 图元（包含有其他局部部件归属的内线），不得画
   bbox 伪轮廓、邻件或 BOM 缩略图。右栏件图视口宽高 1:1，纵向 flex 不得压缩它；图本身
   按 CAD 比例置于正方形视口，可缩放拖拽。
4. 缺少尺寸矩形、多分量覆盖或镜像对应时保留原有未确认结果，不编造完整尺寸；圆盘盒及
   其他既有件数、成本门禁和项目数据不因本修正改变。
5. 图纸派生零件的 `size_quality` 与 `size_source` 必须进入持久化业务件的 `reference` 读回块，
   列表/详情应展示尺寸依据。未直接标注确认的镜像尺寸维持既有成本/工艺门禁，不能因文档组装
   丢字段而被当作确认尺寸。旧的非图纸派生载荷保持原有兼容口径。

## 验收

- 酒盒离线解析：左右盖面纸各约 307.07×528.89 mm；左直接确认、右镜像推断；两者的
  绑定范围均含多组分量，且运行时 `gold_standard_used=false`。
- 任意尺寸合成图应可得到同样规则的结果；移除关键镜像分量后禁止继承尺寸。
- CSS 明确让选件视口不可 flex 收缩；原有包装解析、右栏交互、CAD 预览回归保持通过。
- 图纸派生业务件读回仍带尺寸质量；镜像推断件下游明确返回“尺寸未确认”，不静默放行。
