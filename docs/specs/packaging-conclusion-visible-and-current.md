# 包装零件工艺与成本结果可见性

1. 成本未生成、失效、有效零元必须区分；未生成/失效显示待测算/待重算，不能显示0.00。
2. 清单版本变化不能直接把旧结果改成新版本。仅当该零件当前输入与其历史清单中的输入完全一致时，可复用；尺寸、材料、几何归属、组成、用量、工序或成本输入变化仍失效。
3. 业务零件显示其业务编码对应的已保存工序；不走几何碎片编码接口，不因没有闭合几何隐藏已有结果。采购件明确无需制造工序。
4. 选择零件只读结果；禁止自动调用模型、重新生成或覆盖历史记录。异步响应必须检查当前项目和选中零件。
5. 本轮实现和测试在本地，未授权重新部署或写线上项目；上线后的旧结果是否可以复用须经上述逐件判定，不以绕过版本门禁解决。

验证：新增测试首次运行因缺少复用模块ImportError失败，完成后新增5项及相关回归共87项通过。前端JavaScript语法检查、diff检查通过；未执行浏览器视觉验收。POC整单重算后，同版材料费自动同步到逐件记录，不把整单加工费重复分摊成材料费；有缺口或版本不匹配时不落逐件成本。
