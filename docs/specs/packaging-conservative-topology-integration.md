# 包装拆件：保守拓扑组合接入现有流程

## 范围

将离线实验 C 接入图纸解析及显式重新推导业务件的文档生成链路，不导入实验脚本。不开新步骤，不要求人工确认，不在 GET/加载历史时重新拆件，不覆盖人工归属或手工组成。不提交、推送、部署。

## 规则

1. 现有候选包含全部原选图元，且存在真实 CAD 圆外轮廓包围全部成员时，允许从孔洞碎片切到完整外形。禁止凭名称、文件 hash、固定尺寸、件号或目标数量补答案。
2. 真实圆内的内部轮廓/工艺线随母件保留，只产生一个材料组成，不把每个孔作为材料。圆在既有非圆闭合外形内部时不能反过来扩大为材料。内部轮廓不等于已证明的孔，更不能据此自动扣材料面积。
3. 同一文字锚点、同图框、同方向、比例相近、间距受控的 2–4 个独立闭合长条可合并归属于同一零件；每片有独立尺寸、实体、用量和组成 ID。禁止宽泛同名并集。
4. 新增成员必须存在于真实 IR，不抢占其他零件（尤其人工选择），不得跨方案、吸入标注实体。未知/无证据时保留原结果。不移除原成员。
5. 输出满足既有 sections 契约：稳定 section_id、真实实体、有效状态/用量、独立 bbox/estimated_size；重复 hydrate、保存读回不能再拆成孔洞。人工改选后旧组成不得复活。
6. 选中候选 ID、候选实体、绑定实体、预览范围、组成实体必须一致。候选说明可追溯规则及原候选；不伪造模型/人工确认或 CAD 标注尺寸。变化使业务版本变化，后续工艺/成本沿现有版本失效机制重算。
7. 已有零件名称、数量、编号、方案不变。酒盒冻结基线 28 行逐字段相同（并非要求任意图凑成 28 件）；无变化时不添加元数据扰动版本。

标注启发式可能将长条闭合边界误标为标注线。已选实体和同锚点、无异名反证的完整闭合候选可作为反证保留；不能仅因在圆内就重新纳入任意被标为标注的线。

## 验收

- 合成红测覆盖完整外圆、内部孔不增材料、多片长条独立尺寸、反证与占用/方案保护、人工保护、输入不变/幂等、hydrate、候选一致和真实文档入口接线。
- 原始酒盒/圆盘盒重新解析，酒盒全部业务行与冻结基线逐字段比较；圆盘盒核对面卡/灰板外径、材料组成、条片数量及下游输入，不把变化条数当准确率。
- 记录尚未解决的漏件/复杂弧形/多视图问题；不宣称圆盘盒全对或已完成线上验证。
