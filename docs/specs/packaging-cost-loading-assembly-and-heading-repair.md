# 包装成本读取、空组装结果和重复标题编号

## 2026-10-16 范围

沿用已有项目，不重新拆图、不代改人工绑定或历史成本；本轮仅本地修复，不提交推送部署。

1. 已存成本首屏不得读取/深复制完整 CAD 业务部件、候选图元及历史版本。读取同一已存成本账，零件仅取当前版本的编号、名字、方案、用量等必要字段；保留多方案过滤与每盒用量。文件热缓存投影在复制之前裁剪，冷读仍需解析原文件但不复制其大图元。SQL 后端行为兼容。首屏仍为待核验，不能作为成本确认依据；后台失败保留已有金额并提供重试。首屏读取失败也可自动尝试核验出口，不把一次失败当成无数据。不增加超时来掩盖重路径。
2. 排模开料缺口不能阻止独立的跨零件组装推荐；选择方案与实际零件是生成前提。排模缺口在排模/材料核算环节继续披露，不伪造关联或用量来通过。
3. 组装仍由完整业务零件作为单位，一次模型调用。提供按零件名称/角色识别的低置信候选关系，供模型判断，不自动将候选变成真实连接。禁止按酒盒编号硬编码、禁止制造一条整机总装充数、禁止复制单件制造工序。
4. 多零件却未取得任何可用连接的空结果不能永久缓存复用、不能自动确认或显示正常完成；给出可见缺口与重新生成入口。合法单零件无新增工序、已全部被单件工序覆盖，仍与失败区分。部分连接缺失时保留有效工序并标部分完成。任务后端终态、页面卡片和工作区披露一致。模型不可用不冒充 AI 成功，不虚构连接或标准工时。
5. 按用户澄清：报价右侧分区标题保留原蓝色数字块，只移除标题文字前的①②③等圈号。蓝色编号以固定表单模板与当前步骤为准，分区DOM按模板顺序排列、每步从1连续编号；不能受模型返回先后、重复渲染、错误传入step或回看其他步骤影响。第1步产品信息/技术参数分别为3/4。保留顶部1–6业务步骤导航、业务数据及历史回看能力。
