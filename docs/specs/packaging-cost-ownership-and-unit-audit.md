# 包装成本归属与单价审计

2026-10-13；用户授权本地实现。不得部署、覆盖线上成本或臆定目标价格。

1. 零件成本仅归集材料及实际制造加工；独立人工、出货包材、工装等项目费用归最终整件。原明细保留零件/工序关联，不删费用。加工公式中包含的人工不再另加。
2. 同一本公式账不重复累计：零件材料加工合计+项目费用=整件单只成本。独立人工移层不改变总额，非法金额、未知零件仍报错；有材料/加工缺口不能靠人工金额冒充有效零件成本。
3. 接口明确unit_cost、order_total_cost、quote_quantity和元/只口径；前端零件只显示材料/加工，整件显示人工及包材，并同时显示单只及订单合计。不得把订单总额当单价。
4. 报价其它加价支持运输、资金占用、保险、佣金、商务服务、加急及专项检测；人工/产品包材不迁入利润。已有成本中的运输不可再次作为同一运输费加价；新报价明确扣除成本已含运费后只在加价层计一次，旧包兼容可复算。
5. 异常核对使用真实明细：排序找高额行，披露单位/用量/排模/工时/费率/最低收费。不能按酒盒名称写死价格、删除真实工序或硬压总额。工时秒与小时换算、材料克/千克与吨价格换算保留确定性规则。
6. 历史费用来源不覆盖，模型与规则估算继续披露。测试隔离临时数据库，不写线上业务数据。

验收先跑新增红测，再实现；最终记录实际酒盒验证范围与数值来源，未核对到的项目不得宣称已核对。
