# 包装demo自动贯通（无需人工确认）

状态：Spec + 红测（已实现）；仅本地，未部署，未做线上浏览器全流程。
红测：`tests/test_packaging_demo_auto_close_loop_red.py`

沿用原有按钮顺序，不新增“一键贯通演示”按钮或独立启动API。自动几何模式的包装图纸项目在既有单件/批量工艺、BOM、路线和成本入口内部准备demo输入，自动采用盒型匹配、补齐逐件工艺、BOM、路线、统一成本、交接包与报价草稿。每一步有进度和错误；不要求逐项人工尺寸/参数/路线确认，不伪造人工签字。保存自动采用来源与估算披露，不发布正式报价，不改已有项目权限，不自动对外发送或部署。auto_geometry_inputs=false关闭自动demo准备，非包装/非图纸项目维持原行为。

盒型只选已有可匹配候选，不能越过跨行业和尺寸冲突；保留已有确认盒型。无可用候选时如实失败。新图纸可用相似参照+模型，模型故障可明示demo基础工序估算。多组成尺寸、材料、用量分别保存与计算，不为贯通清空组成。

前端单件和批量统一走业务件输入，不回到旧几何/闭合轮廓门禁；自动估算尺寸参与相似推荐但标记未验证。BOM消费与单件相同的自动尺寸，不能再只认confirmed_size。

尺寸优先级：已有确认尺寸 → 当前bound且有实体的完整CAD候选长宽/包络 → 原参考尺寸/分量估算 → 明示占位。不能把组成碎片逐轴最大值当成整个已选区域尺寸。准备规则版本变化必须触发重新准备，已保存旧工艺按既有版本门禁重新计算，不冒称仍是当前版本。

仅自动估算模式下，无法识别材料时采用明确的“未识别材料（估算）”标签及demo_unknown_material来源，保留克重/价格估算披露；不能假称某种真实材质，也不能一边给估算成本一边因空材料拒绝原有工艺入口。非估算模式仍按真实缺口拒绝。

3.3参数与项目路线同步到原有整合工作台：包装必填参数由需求和明确demo默认补齐，自动采用标记的by字段为“自动采用”，不冒充操作员人工审核。既有参数推荐入口在无额外说明/附件时复用现有需求，有额外输入保留原推荐能力；组装工艺入口采用同版包装路线，不另建3D加工费用。未归组原始图元只有在完整、互斥覆盖当前选中实体时才可作为demo剩余部分估算，保留原始缺口说明。上机尺寸和未分类尺寸不直接冒充纸张，demo用关联件横排包络另作开料估算并保留原尺寸证据。

API与前端现有按钮样式、任务进度和会话气泡兼容。任务输出包含统一成本、28件等动态数量、交接包和草稿价格，不写固定酒盒尺寸或件数。只允许现有有成本操作权的用户发起，并检查项目访问权。
