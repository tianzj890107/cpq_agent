# 包装演示一次跑通验收

演示路径从销售新建精准报价开始，经原 DWG 派工、工艺接单、需求确认、图纸解析、批量工艺和财务核算，回到同一张报价做定价与输出。使用独立验收单和样本图纸，保留账号之间的审批权限和真实交接。34 使用 `947f62c` 的报价首页、需求确认页和技术工作台。

## 工艺推荐与确认

- 用同一张新单覆盖可以从图纸取尺寸和材料的零件，以及需要演示兜底的零件。在前一件已经保存工艺时触发后一件的演示准备，批量首次完成后应能读取全部当前有效结论，且「确认工艺」可用。已完成结果仍能追溯到各自采用的尺寸、材料、工序与演示假设。
- 真实几何、材料、数量或影响工艺的输入变化时，按实际影响范围失效。演示准备改变存储结构时，以本件是否能继续使用原工艺为准，不能用整批任务成功掩盖失效，也不能靠一律忽略业务字段的方式通过验收。
- 已知任务 ID 后，单次状态查询网络超时，使用同一 ID 在现有最长等待窗口内恢复查询。仅后端终态失败、工序为空或持续失联达到等待上限时记为失败。查询重试不新建任务，保留在前端展示实际等待状态。

## 交接验收

- 工艺确认后，向指定财务账号交接。财务领取后能打开同一技术项目，读到当前有效成本账、核对有金额的零件覆盖和对账结果，然后确认并回传。演示估算与适用范围应可见。
- 财务交接任务带有工艺确认版本时，财务按该版本测算。演示所需的价格、开料参数和工时默认值只在成本计算时使用。需求单、原工艺和路线保持原版本，成本读回标为内部估算。已确认工艺发生变化时提示重新交接。盒型未确认时，交接直接显示盒型缺项并保留工艺确认。
- 对图纸演示项目，发送时可补建缺失的盒型决策。需求明确选用了在库盒型且已有资料与之兼容时，自动沿用该盒型；缺少的演示尺寸取该模板已登记的内尺寸区间，记录来源，且只供 BOM、路线和成本。原审核需求和已确认工艺不变。候选不唯一且无明确选择、输入冲突、仅有历史演示默认值或存在人工退回决策时，不自动换型或覆盖人工决定。报价人员仍须由工艺人员明确选择。
- 回传核对源销售会话、财务任务终态和销售接收的成本版本。报价步骤读取回传版本，核对定价与内用 Word 输出的对应关系。正式发布门禁仍按现行规则执行。
- 发布验收记录精确提交、三页页面指纹、各步结果与耗时，区分首次通过、从已提交任务恢复读取、需要重算和未覆盖。两份 DWG 只按各自已跑步骤记录结果。
