# 包装成本改用成本测算明细口径

## 范围与分批

用户授权：实现、提交、双远端推送、部署34、线上验证。三批依次进行：1规则与实际失败红测；2公式选取/参数/排模/归集/前端；3回归、精确提交部署与线上验证。

可见来源仅《成本测算明细.xlsx》的报价-行业标准与包装运输；隐藏表不采用，BOM示例名/尺寸不作为新图识别答案。运行时不读Excel、不让模型计算金额、不降低材料价掩盖公式差异。旧0903公式与黄金测试保留为历史口径。

## 规则

- 包装新项目成本采用detail_sheet/1：材料基础公式，覆膜U2、热烫W2、裱纸AG13、啤切AH2/AH9、V槽AJ5/AJ8、胶水AM2/AM4。新的公式编码与来源独立，不覆盖人工维护旧公式。
- 覆膜MAX(200/Q,面积×膜价/税因子/模数+面积×膜重/1000×重价/模数+0.15/模数)；热烫MAX(150/Q,烫金面积×箔价+0.3/模数)；裱纸MAX(100/Q,上机长/25.4×上机宽/25.4×0.56/1000/模数)。
- 啤切MAX(100/Q,单模费/模数)，默认0.15，0.08须明确变体/参数证据，不按零件编号特例。V槽MAX(150/Q,0.15)×次数，默认1；不能除模数。胶水有实际涂胶面积时优先该面积，否则上机面积/模数，实际面积不重复除模数。
- 缺少公式的UV/普通印刷等不猜零、不声称来自明细；已有UV公式保留0903来源。组装人工仍按新增跨零件工时×费率，不照搬AN15的8.44元。费用展示材料/加工/其他费用；不计模具摊销与运输。
- 单个工序加工费须包含制造人工，不再为已含人工加工补同名劳动行。独立制造人工仍归加工；最终组装人工归其他。
- 新规则独立JSON随代码发布，含SHA、原单元格公式、变量映射、默认费率/参数、最低收费、版本。内置与KB reviewed新编码一致；缺新KB行采用同版本内置规则且明确来源，不回落0903对应工序。
- 多零件排模按整张工艺计算再按生产需求/展开面积分摊，不对每个零件收一次整张费用；没有排模的使用各件自有上机参数。不得把整单数量重复当零件用量。

## 持久化与前端

公式选择必须同时切换默认参数、来源单元格及版本。源规则变更使旧成本待重算，原账金额/原报价保留；旧报价显式重算后再引用新版本。成本详情中文展示新字段和最低收费，不新增字体/大按钮，MAX保留。

## 验证

按1000/5000/10000/20000批量、模数1/2、次数1/2核对五类加工。验证新旧规则独立、KB覆盖正确、真实写入回读、组装归层、排模共享工艺不重复、前端详情及报价同账。离线工具核对公式原文和工作簿SHA，不能用缓存值冒充公式。线上用新验收副本，不覆盖用户历史项目。

已实际运行红测：初始缺少cost_profile选择参数，新项目仍为packaging_v1；共享排模缺少共同加工分摊；25.4小数在白名单首层误被拒绝。分别补入口、分摊和仅数字小数点检查，反射/属性访问仍禁止。旧规则黄金值不改，只修订新项目应引用的新规则编码和版本、路线读取测试的费用政策夹具。

注意AH9的模数原单元格为空：离线验证明确使用合成模数1验证公式，不声称该行已有真实价格或把IFERROR空串当0。实际运行必须取排模/工艺参数；V槽次数1/2泛化来自AJ5/AJ8，胶水实际面积来自工序证据，不把AM4的4920平方毫米写死给其它件。

线上验收追加：原默认给每个未知组装步30秒，模型拆12步便膨胀成3.60元。没有真实标准工时的估算统一整盒30秒预算，在估算步骤间分配；有真实标准工时的项不改、不设金额上限。保存原路线工时、预算、步数与分配规则，计算输入如实说明。旧poc_mock路线在显式成本重算时按共享预算解释，不覆盖原路线历史；新组装推荐直接分配预算。工时政策另存来源版本，旧成本待重算。
