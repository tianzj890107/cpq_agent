# 包装拆件：图纸顺序、完整圆形、原生尺寸与顺序归属

日期：2026-10-09。用户授权本轮直接实现；不部署、不覆盖历史项目。

## 1. 输入与独立验图

只读 DWG/DXF 的文字、实体、图层、标注。先生成独立 CAD 图及文字/圆/标注账本，再比解析结果；BOM、酒盒答案、固定件数和样本尺寸均不得作为生产输入。
圆盘盒两方案分开：左侧为零件，右侧排模不混入件清单。圆板可能带内孔、内部刀线；一个名称可以对应多个物理部分。包围盒不是轮廓，圆内碎线不是整件。

## 2. 图纸顺序

DWG 没有业务清单顺序字段，统一采用 CAD 坐标空间阅读顺序：文字行从上到下，同一行从左到右；行容差由文字高度确定，稳定 ID 只处理位置相同的平局。无定位的推导件置末尾并披露来源。实体输入倒序不得改变结果，平移不得改变顺序。重解析新版本可以重编号，不重写旧版本。
排序在候选归属之前生效，并把 sequence_no、drawing_order 写入实际业务行；前端不得另按名称/编码/评分排序。

## 3. 完整圆形候选

真实闭合外轮廓与其内部实体形成整件候选；须用实际曲线/多边形验证包含，不仅用矩形重叠。同心内圆要显示，不能只拿孔径作为整件尺寸；相邻圆、落在圆的矩形角外的图形不能吞并。内部实体仍保留独立证据，复合归属可撤销。
圆形完整候选优先于被包含的单片；候选注明完整外轮廓来源、实体 ID 与标注证据。圆、圆弧、椭圆、带 bulge 的多段线继续使用同一曲线展开。模型只审语义，不创造尺寸/实体。

## 4. 顺序归属

前件已选的 CAD 实体，后件不能重复选。前件选择被后件占用的候选时允许接管：后件旧绑定与尺寸进入历史，当前绑定/组成清空、需重新选择，不能继续使用旧尺寸或成本。输入文档不原地修改。
候选实体冲突与 component_ids 冲突都检查，手动组成选择不得绕过。自动选择按清单顺序，每件优先最高证据分；冲突候选保留供审计，不静默吞掉候选。相同操作幂等。

## 5. 图内尺寸

保留 DIMENSION 的 CAD 显示图元（尺寸线、界线、箭头、文字/旋转），不是从 bbox 造一组尺寸。圆直径/半径符号保留；显式文字覆盖值不被实测值悄悄覆盖。显示账与计算账分离。
整图和单件预览均显示相关原生标注；单件按标注见证点或明确标注引用选取，不把邻件标注带入。显示范围包含尺寸文字和线，默认 fit；保持正方形预览。标注永远不成为零件外轮廓实体。

## 6. 下游事实与已发现问题

不得将归属自动确认当作尺寸业务审核，不能伪造权威工时/材料/价格。独立 CAD 标注确证可传入单件组成；缺证据仍保留缺口及 POC/正式区分。
上一轮 22 项问题见 `docs/reports/online-packaging-e2e-20261009.md` §4。本轮修复 01/02 的部分根因及顺序/尺寸显示，但未达到这两项整体关闭条件；03/04/12 的模型预算与真实工序成本需要真实数据回归，不能以件数或模板 200 代替；05–22 本轮尚未实现，不把未实现写成已通过。

## 7. 自动验收

合成非样本名称/尺寸验证：空间顺序、反序/平移不变；同心圆与内部线完整候选、圆外 bbox 角拒绝；前件接管、后件拦截、组成选择同一门禁、历史保留及失效；原生 DXF 直径标注进场景及单件 SVG、原始文字和定位保留。旧圆弧/椭圆/颜色/多组成/正式门禁测试不得回归。
真实圆盘两方案离线对比记录每件名称、外轮廓、组成、显示标注、尺寸来源和顺序，不追求固定数量；本地验证不等于上线验收。

## 8. 实测新增的阻断条件

- 一个实体的正视图、侧视图、透视图不得分别计作物理组成或重复计费；展示可保留参考视图，计算必须区分。不能仅以名称接近、图形数量判定多组成。
- 相邻行、列与未命名材料图形不得因最近名称吸附进别件。无充分证据则保持待分配，不以绑定率作为目标。
- 历史 IR 未保存原生标注显示图元时，需要明确重解析或补兼容读取；不得声称旧项目会自动出现完整尺寸线。
- 原始 CAD 的圆直径可独立用于核对，但本报告里的样本数值禁止回写为生产规则。证据排序分不是正确概率。
- 旧冻结测试的 263/312 是几何碎片数量，不是业务件数，更不能阻止新增真实曲线参与识别；后续替换为图元覆盖、标注不混入轮廓、准确形状与面积等证据断言。
