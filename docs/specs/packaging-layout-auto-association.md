# 排模自动关联与折叠动作

折叠或展开时，关联零件标题与保存关联保持同一行（极窄屏允许换行），保存不触发折叠。复选列表仍可编辑，保存语义不变。

新解析的排模依据 DWG 文字自动关联：排模文字明确包含完整业务件名时关联；较长件名覆盖短件名，不以“底板”误关联“地盒底板”。不存在文字证据不得靠几何距离猜，不推导用量、批准排模或成本。保留证据文字/实体ID。人工关联（包括清空）优先，不自动覆盖。旧文档读取不隐式改写历史；旧文档须重解析得到新自动关联。

本轮只使用可验证的完整文字证据；没有名称的排模图案跨区域几何相似识别仍是缺口，不声称所有排模自动命中。
