# 包装零件区域优先自动归属、阅读顺序及尺寸一致性

## 1. 目标与事实边界

新项目解析自动选择名称归属明确且组成完整的 CAD 候选，不要求逐件重新选择。主要路径为排版区域内收集原始 CAD 图元；完整单区域仍可选。禁止按零件编号、候选序号、固定尺寸、BOM 答案实现。

2026-10-12 最新线上参考项目 651e814359a3，BP01–26 为人工绑定；其中 22 个 layout、4 个 region。人工绑定不等于已验证正确。用户指出 BP05 当前不完整，BP06 候选1实际上是完整 BP05；这是待定位的区域/文字关联错误，不能硬编码交换。BP02 保存候选及组成尺寸约44.59×273.92，但新打开页面卡片为217.06×482.92，已复现不同数据状态。

## 2. 区域和文字归属

先定位现有管线的失真层：原始区域、区域图元、文字关联、筛选、排序逐层保留可检查证据。优先修现有通用缺陷，不新增全图重分配或邻件交换机制。

件名可在区域外；结合区域边界、文字排列、引线及标注目标识别归属。距离或文字落入 bbox 不能单独确权。不同件名共享区域时区分实际几何目标；`mixed_name_owners` 必须有真实冲突证据，不可仅因包含多个附近名字就误杀。

## 3. 完整候选与自动选择

区域内从原始实体收集直线、圆弧、圆、样条、多段线和独立组成部分，排除图框、标注线、邻件。过滤后的几何分量仅是索引，不能成为唯一实体成员来源。

分开评估名称归属与完整性。经 CAD 证据验证的布局候选可升级为 supported；不能永远因生成来源为 layout 而 ambiguous。未验证的区域大框不得自动升级。存在同名、同区域且尺寸目标验证的完整候选时，其内部碎片不得胜出。unknown 图层不构成 same_boundary_role 正向证据。

相同实体集合合并候选，保留全部来源；不同实体集合在预览中揭示差异。不按面积最大或 layout 前缀盲选。已保存人工选择不在读取或自动补算时改写。

## 4. 顺序与身份

按最终零件所在区域从上到下分行、同一行从左到右排序；CAD 的上方为较大 Y，容差由区域尺度/行结构推导，禁止样图坐标阈值。标题、排模重复区域不编号；不同方案先分组，方案内排序。

新增纯函数 `order_business_parts_by_regions(rows)` 返回排序后的副本；输入每行 geometry_binding.bbox 和稳定 business_part_code，输出连续 sequence_no。此函数不修改稳定业务 ID，不重写历史关联。新建图纸解析可按最终顺序生成可见编号；历史项目需保留稳定 ID，通过显示序号表达新顺序，禁止直接改主键导致下游失联。区域未知的行置末尾并披露，不能按错误文本位置插入。

## 5. 尺寸与预览一致性

绑定、sections、reference、confirmed_size、卡片、候选预览、BOM/工艺/成本须引用同一候选身份和版本。改选归档旧尺寸证据并失效旧派生值；不得在 UI 中以旧 reference/confirmed_size 覆盖新 CAD 证据。无新证据时用选中候选的估算并标注来源，不能沿用旧件尺寸。重新 GET 后显示与保存结果一致，不能只修本地即时 DOM。

兼容旧数据时，为历史尺寸补足绑定关联或明确标为归属待核对，不静默当新候选的尺寸。预览使用当前预览候选而非持久化旧候选，适应窗口包含尺寸文本范围。

## 6. 红测与验收

`tests.test_packaging_layout_first_auto_selection_red` 为确定性合成数据测试：完整区域候选优于内部碎片、unknown 不加边界证据、按区域而非文本顺序排序、旧尺寸不得覆盖新绑定。无网络、无生产写、无BOM输入。

实现方还须补充真实区域生成→名字关联→候选去重→自动绑定集成测试：外置名称、两区域相邻、断开组成、圆形/多轮廓、缺失框线、排模重复；候选/实体顺序打乱、平移和比例变换结果保持语义一致。旋转后按当前图纸阅读方向重新排序，不要求旋转后顺序与原图相同。

首次运行：`./open-claude/.venv/bin/python -W ignore -m unittest tests.test_packaging_layout_first_auto_selection_red`，4条均失败。完整区域/碎片70分打平；unknown被附加same_boundary_role；缺少区域排序函数；旧200×400尺寸覆盖新42×93尺寸。尺寸用例复现通用旧状态优先缺陷，不宣称它已经证明线上BP02串状态的唯一根因。件名错配、去重和圆盘盒识别尚未由本文件完整覆盖，必须补集成测试，不得只调整分数使四条通过就结束。

酒盒26件参考逐件检查，BP05不计已确认金标；圆盘盒需独立原图核对，未核对不可宣称准确。报告候选是否存在、名字是否归属、实体是否完整、尺寸是否一致四类结果，不把实体集合相同比例当泛化准确率。

## 7. 禁止与交付

禁止生产数据覆写、自动部署、推送、改写人工历史、禁用证据门禁掩盖错误。交付代码审查、红转绿及既有包装候选/阅读顺序/尺寸测试回归；本地测试通过不等于线上识别验收通过。

## 8. 本地实现补充

- 标题上下方向由当前图纸的文字与区域证据推断，外置标题按实际文字跨度及区域关联；不固定所有行业标题在下方。
- 原始布局区域独立关联标题，复合件复用同一归属结果，不再次按最近距离吸入邻件；同实体候选合并时不重新注入已被完整区域校正的碎片名字冲突。
- 几何文档保存轻量原始实体注册表。只有服务器候选、有效名字区域证据、且每个实体都存在于注册表的原始布局候选，才可以不受保留分量面积筛选限制确认几何归属。未知实体仍 partial；该确认不赋予标注尺寸或材料证据。
- 多个独立闭合部分保留分部尺寸；额外图元无法归到具体部分时保留为待归属部分，不丢弃、不用区域并集代替全部尺寸。
- 新解析产生 display_code/sequence_no，稳定 business_part_code 不变；历史读取不重排或覆写人工记录。
- 改选归档旧 confirmed_size/reference 尺寸，保留材料等无关字段；新确认写入候选身份。前端对无身份旧尺寸优先使用当前 CAD 分部证据，不把没有几何对应关系的旧值当当前尺寸。
- 单件视窗保留渲染器计算的含标注范围，预览高亮使用 figureBinding，不用旧持久化绑定重设 viewBox。前后端评分同步。
