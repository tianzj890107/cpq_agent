# 包装 DWG 拆件：图框空间候选与模型语义复核组合（2026-09-28）

## 目标与边界

`dwg_split.py` 的“正式图框 → 空间聚类 → 文字归属”可作为候选生成能力复用，但其酒盒配置中的绝对坐标、3 mm、人工 `text_fix`、27 个预填名称及顺序不是通用规则，也不能在 CPQ 运行时读取。CPQ 已有端点连通分量与视觉模型复核；本次把两条确定性证据合并为**竞争候选**，不以某个样例件数作目标。

1. 从 CAD IR 自动探测可回查的封闭矩形图框；有可信图框时给分量赋框 ID。没有可信框时保持无框状态，不能把图外内容静默删除；旧过滤器未纳入的原始几何至少保留为单体弱候选，不凭空合并。
2. 保留端点互补候选；新增同一图框/视图内包围盒相交或小间隙的空间候选。候选既要覆盖已保留的几何分量，也要从原始 CAD 图元聚类补回被旧过滤器遗漏的短线、弧和样条；原始候选必须保留可回查图元 ID，并将图元与已保留分量分两本账。空间/原始候选只表示“可能同件”，必须是 `ambiguous`，不得据此自动绑定、确认尺寸或进入成本/工艺的权威尺寸通道。异框分量不能因距离近跨框并件；显然不相邻的分量不能仅因同框合并。
3. 候选包含来源规则、实体和分量 ID、框/视图 ID、证据与反证；按当前件名锚点的空间关联对单片/多片统一排序，不能固定先塞若干单片导致整件候选被截掉。未绑定的多片候选要在业务文档中另列、在看板中可折叠查看图形；不计入业务部件数，不给工艺/成本按钮，不得伪造业务件名。原始单片仍留在几何证据账。
4. 候选附带同框且距离合理的 CAD 原文文字及位置，不替换原文；视觉模型读取局部彩色图、紧凑候选证据和这些文字，只可选择已有候选、判别名称/材料/图例或拒答。模型结果是弱建议；即使选中多分量整件，也必须保留完整成员 ID 供人工确认，不自动产生 `bound`、`size_confirmed` 或正式尺寸。模型不负责自由划边界。
5. 图元分组须有空间预筛和每分量端点缓存，避免在真实图的数百个分量上对所有两两组合反复遍历几千条线。模型预算只影响复核次数，不应影响候选生成或未审件的安全降级。
6. 一键解析与旧项目补推导走同一解析路径；不改下游已确认尺寸门禁，不读 BOM/Excel/金标，不改已有数据或历史版本。真实图至少测试酒盒与圆盘盒，另用独立合成图测试跨图框、平移、顺序和错误合并。

## 验收口径

- 两段端点不接、但处于同框且相距很近的图元能形成**待确认**整件候选；相邻异框件不混入。
- 对无可靠图框的图不丢任何原始单片候选；图框只作候选证据，不替代几何事实。
- 候选来源/成员在模型拒答、超时、预算耗尽后仍可查看；模型选中整件仅记弱建议。
- 无件名候选面板可以选择现有业务部件进行人工关联；服务端只采用候选账中已保存的实体 ID，拒绝不存在的候选或业务件、拒绝与其他已关联件重复占用实体。关联原始候选只表示归属核对，不确认包围盒尺寸；前端只画该候选的精确实体，并继续关闭依赖未确认几何的工艺/成本入口。
- 仅确认过滤后的分量时，不得把尚未归属的原始弧/线从待核对队列中消掉。
- 合成的大量相互远离分量不会触发全量两两端点重算。
- 独立样图验证数量、图元归属、误合并和性能；不能把“酒盒凑到 28 行”当合格条件。
