# 手动CAD候选允许重叠

手动选用已存在、图元有效的项目候选不得因其他件占用而拒绝；保留其他件选择、尺寸与组成，不自动抢占。当前绑定记录重叠件编码，并提示“图元重叠，允许手动选用”。自动选择仍按既有顺序占用规则处理。无效候选/跨项目ID仍拒绝，重叠不等于尺寸正确或成本可用。

线上只读诊断：酒盒651e814359a3，BP13候选2 layout:ddf036bff292c633 含cmp:35/43/755，与BP05 group:cmp:35|cmp:43|cmp:755相同分量，且BP13有被BP05撤销自动归属的历史。不是按相同候选ID冲突，而是共享实体或分量。

识别后续方向：正确选择仅作为评测标注，不写死业务编号/坐标/候选序号。比较完整名称锚点、排版区域、多组成完整度、刀线闭合、标注归属及候选实体重叠；相同实体集合的候选应归并展示。人工采用记录应在重解析中通过图纸指纹+图元身份恢复，不直接迁移到其他图。新评分必须使用独立图纸和变换样本验证，不以酒盒单图正确率证明泛化。

## 本轮线上选择所支持的结论

读取快照business-parts:5720a90fd23a4825：17件为manual，其中12件选择layout类、9件选择候选原数组非第一项（不是评分Top1准确率）。左右盖面纸均采用3分量区域；内盒2面纸采用4分量区域；内盒3面纸采用3分量区域。应以“名称对应的整件组成是否齐全”评价，而非连通数量少或离文字近就优先；但不能所有零件都偏好最大区域，贴牌选单区域、内盒2灰板选2分量组合。

BP13候选2为mixed_name_owners/ambiguous，BP05已手动选择相同分量。允许人工共享不会证明分割正确：自动管线要重新判名称和组成，区分真正共享图元与一个候选框吞进相邻零件。BP03/BP13当前未绑定、其他部分仍为auto，不能将整个28件快照都标为人工金标。

改进顺序：先独立保存采用结果评测集及同图复现测试；再按名称/分区/组成完整度重新排序并去重候选；最后做全图联合分配，人工锁定优先、不因前件自动结果提前排除后件完整候选。跨图验证涵盖平移缩放、文字换位置、圆形、多个断开组成及采购无几何件。验收不以固定28件、固定候选序号或固定尺寸作为实现规则。

## 本轮实现边界
完整多组成在“互补刀线+同方案+同类边界+几何有效”时增加排序证据；其他件名称/多个名称混杂仍不自动认定。最高分失败后尝试后续有CAD证据候选，不能因一项占用就放弃整件；自动选择不撤销人工绑定。两项新增测试在实现前实际失败。尚未完成名称归属重新建模、跨图准确率评估和候选去重，所以不宣称已经可以自动选对全部零件。
