# 包装整图多方案解析与工艺入口

状态：Spec + 红测（已实现）；仅本地，未部署。
红测：`tests/test_packaging_multi_scheme_entry_red.py`
取代 `packaging-round-box-schemes-layout-multipart.md` 的整图多方案拒绝口径，不取消防混算。

1. 多个“方案”标题不是拒绝解析的理由。保存标题实体、位置和作用域；排模方案与内托/产品方案不得等同。
2. 空间分区仅由图纸标题、件名、几何区域的间隔推断，不得写样图坐标、固定件数或答案。跨界实体保留原图元、不裁切；不明确的归属必须披露。
3. 各作用域独立运行既有解析器，业务编码加作用域前缀。同名不同方案不得合并；方案外证据保留为公共/未明确归属区，不默认相加。
4. 零件与排模记录带方案标识；同名自动关联只在同一作用域内进行。前端显示方案分组及切换入口，沿用已有按钮样式。
5. 选定一个方案之前，整体 BOM/成本不能把不同方案相加。选择在业务文档中持久化并改变版本身份；公共件与选中方案进入下游，其他方案仍保留可查看、可推荐工艺。
6. 批量工艺必须遍历业务零件，不读几何分量；按钮可用态以业务清单为准。缺清单时显示真实解析阻断原因，不能把几百个分量叫零件。
7. 单方案及人工绑定不退化。模型错误不能让步骤假完成：有几何、无业务清单时必须披露未完成原因。

8. 跨多个方案标题的大闭合图框不能当制造轮廓，不能将框内的圆形业务件全部误判内孔。方案内重建 CAD 连通分组；保留原始实体身份，新增分量使用方案命名空间。不凭包围框宽高证明任意零件尺寸已确认。

实现补充：支持上下及左右标题排布；纯排模方案保留一套公共业务件，排模记录分别归属方案。空间推断带 `inferred_from_drawing`，非任意复杂布局的确认承诺。未明确作用域图形保留原图与诊断，不强行当公共件计入成本。

验收：见 `docs/reports/packaging-multi-scheme-acceptance-20261012.md`。工艺批量入口修复不等于解除尺寸/材料证据门禁；未知尺寸不会被伪造为已确认尺寸。
