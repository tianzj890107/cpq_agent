# 零件成本逐行计算依据弹卡

点击成本行/Enter/空格打开只读居中详情卡，重算按钮独立、不同时打开弹卡。原表、每套用量、金额、权限与重算算法不改变。

包装详情来自当前同一estimate的公式账，不重新测算或让模型解释金额：材料/实际加工逐项展示原公式、版本、存储输入参数、原金额、损耗后金额、每套零件用量除数、单件金额、费率/材料来源、最低收费与假设说明。按账的同一损耗规则投影，单件明细之和等于零件单价；独立人工/包装不重复放入零件。

金额详情保留最多6位，面板2位；明确合计使用未舍入金额相加后舍入，避免0.66+3.25与3.92误判。过期、缺记录、坏输入JSON、未保存公式明确披露，不编造依据、不把无数据当0。

打开/关闭不写库、不调用模型或成本接口。卡片可滚动、Esc/关闭/背景点击关闭，关闭恢复行焦点；输入/按钮操作不冒泡触发详情。
