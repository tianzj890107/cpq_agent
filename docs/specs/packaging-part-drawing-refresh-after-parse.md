# 包装图纸解析完成后就地刷新零件图

日期：2026-10-13

## 问题与原因

用户指出：解析后的零件清单可以看到，但零件图纸必须离开页面再返回才出现。
`runDrawingFlowParse()` 的完成回调只重新读取零件与业务部件文档，没有刷新
`currentPackagingCadPlan` 所承载的 CAD 图元坐标。进入页面时读取到的空场景仍留在内存；
已有业务部件时也不会经过补推导后的场景读取，因此点零件无法绘图。
场景读取原来只在成功响应解码后检查项目，较早的空响应、404、网络失败亦可能覆盖新图。

## 可验收行为

1. 解析完成时，立即并行重新读取零件清单和 CAD 场景，仍使用现有纯读接口。
   清单或场景任一先返回即可按既有渲染流程显示，无需离开当前页面。
2. 刷新 CAD 场景时，清除上一份场景坐标缓存，保留当前选中件并显示加载提示。
   用户在坐标返回前点零件时记住该件，场景返回后绘制同一件及其标注。
3. 场景先返回、业务件文档后返回时，两路读取完成后再重画当前选中件。
   场景已按最新业务件绘制时不重复打开零件，避免重复读取其已保存工艺。
   未选中零件时展示完整图纸，不强行选件或切页。
4. CAD 场景只允许当前项目的最新读取写入页面；过期的成功、404、5xx、网络异常和
   慢 JSON 解码均不修改缓存、图形、加载状态或选中件。切换项目时同样丢弃旧请求。
5. 当前读取失败仍显示现有读失败/未生成文案，用户可按既有解析操作再次刷新；
   不隐藏错误，不自动重跑解析，不调用模型，不改变几何归属、尺寸与业务流程。
