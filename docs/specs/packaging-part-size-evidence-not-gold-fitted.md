# 包装 DWG 尺寸证据：撤销样本特化修正

## 本次修正

上一版 `packaging-composite-part-dimension-and-square` 将酒盒样本中的“标签在矩形下方、三块
几何覆盖九成、左右同尾名镜像”提升为生产规则。即使没有直接读取 BOM，这些阈值和方向假设
也是针对单张图得到的，且只使两个面纸尺寸对上，不能代表全图识别质量。本次撤销该自动改尺寸、
改绑定、拼整件的规则，不把 307.07×528.89 或该样本的布局方式留在运行时逻辑中。

保留两项独立修正：选件图视口不可被 flex 布局压扁；图纸派生业务件的 `size_quality` / `size_source`
在读回文档中不得丢失，未确认的包围尺寸须在页面披露并被既有成本/工艺门禁拒绝。已保存的业务
件文档不因读接口自动改写；需重新解析才会生成新版文档。

## 后续通用识别的验收口径（本次不宣称实现）

1. BOM/报价资料只放离线答案集；运行时只能用 DWG 的图元、文字、标注、图层和几何关系。
2. 先确定一件的图元集合及外轮廓，再计算尺寸；“离文字最近的一块连通碎片”只是候选，不能
   直接当整件。标注必须与候选图元有可追溯的空间/引用关联，不能仅因数字相同就确认为本件。
3. 镜像、重复、嵌套、开口轮廓都应作为候选关系，与非镜像、非重复的反例共同评测；证据不足
   时保留候选和不确定性，不输出精确已确认尺寸。
4. 用多张不同盒型/排版的 DWG 做训练外验收，按全部业务件统计名称、图元归属、尺寸误差、
   置信度校准和下游门禁；酒盒的两件面纸只是错误样例，不是单独的通过标准。
