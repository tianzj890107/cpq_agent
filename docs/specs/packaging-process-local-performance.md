# 工艺推荐本地性能优化

2026-10-19：仅本地实现与对比，不推送、不部署。保留其他未提交修改。

## 边界

1. 单件工艺GET只复制当前件及清单身份，不为读已有工艺复制全部CAD候选、全图实体和其他件。返回的工艺、版本失效判据、404与权限不变；写入/推荐仍使用完整证据。
2. DA缓存作用域内同一键并发冷读合并为一次HTTP，其余调用等待同一结果，返回独立副本。不同键不互相阻塞；失败通知所有等待者，不缓存，后续可重试；TTL=0或作用域外不合并。缓存键包含桥接地址与内部身份，不跨数据源复用。
3. 模型调用数量、提示词、费率、推荐及成本口径不变。不按左右件名称或相似度直接复制另一件工艺；尚无完整输入等价证明，跨零件模型复用不在本批上线。
4. 用隔离临时目录的28件大CAD合成数据测真实GET读路径，修改前后同一夹具多轮取中位数，检查响应一致。DA用可控延迟桩测并发重复请求，不冒充真实数据库或真实模型测速。

## 验收

- 单件读不调用全量业务件读取，深层修改返回值不污染存储；文件更新后立即读新值，不回退历史清单。
- 当前件不变/变更、旧按组成工艺、无记录、缺件、权限保护维持原行为。
- 3个并发同键只读一次，失败三者均结束且下一次可重试，不同源隔离、禁用缓存兼容。
- 记录本地中位耗时、请求数、样本规模、结果一致性。明确不据此承诺线上整批生成加速比例。
