## 现场复现

34 的包装项目已完成图纸解析，28 件业务部件可读。批量提交全部失败。切换公司模型后单件提交同样返回 HTTP 500，后台任务列表为空。接口在提交任务前调用演示输入准备，失败的请求新增了需求保存审计。需求中出现了与酒盒不符的圆盘盒演示模板。服务器异常栈尚待核对。

## 验收

1. 单件工艺推荐先加载当前业务部件并用既有方法验证本件尺寸、归属与材料。有充分证据时，经原有任务提交入口生成整件工艺。已审核需求缺少项目级盒型确认也不阻止这条单件路径。保留后续 BOM、成本、工艺确认和发布门禁。
2. 已审核需求的单件工艺提交过程不得写入需求、替换盒型、更新其他零件的输入或重置图纸与会话。证据不足时走现有 409 和证据缺项提示。批量入口仍逐件调用相同接口并保留逐件失败原因。
3. 已允许使用演示输入的流程如需补齐数据，只能使用与已有证据兼容的模板。明确被拒绝的候选即使分数最高且尺寸未超界也不能提供盒型或尺寸默认值。演示前置条件未满足时，保留首次调用前的需求、有效结果和确认状态。已知盒型匹配冲突返回可读的 409 JSON，错误码使用 `demo_box_match_missing_or_conflicting_inputs`。
4. 使用新建隔离项目或合成夹具验收，覆盖有证据成功提交、缺证据阻断、不兼容候选拒绝、失败前后状态对比。历史项目只做恢复和读回核对。
