# 包装工艺统一参考件与AI推荐口径

状态：Spec + 红测（已实现）；本地验证，发布状态以提交和部署记录为准。
红测：`tests/test_packaging_process_reference_presentation_red.py`

## 范围与验收

- 包装工艺不再展示“标准工艺”或固定70%/默认60%的工序置信度。库内直取展示“参考件相似度 XX%”，AI生成展示“AI 推荐”。不影响其他行业。
- 相似度仅使用检索返回的真实有限0～1得分，不使用审批状态、工序confidence或名称命中来伪造分数；没有评分展示“参考件相似度：未评分”。评分描述的是参考零件，不是工序正确概率。
- 展开依据可见参考件名称/编码、评分分项、缺失特征、匹配方式、参考工序及推荐理由；AI借鉴参考件可同时显示真实参考相似度，但工序身份仍为AI推荐。
- 新工序携带逐工序展示来源，多个组成、混合路线不能被整件统一标为同一来源。保留原数据库引用、审批、真实标准工时、顺序、依赖与成本逻辑，不改变权限/审核/确认门禁。
- 历史包装方案无需重跑、迁移或改写，前端从coverage及各组成coverage补充展示来源，不把旧confidence当相似度。非包装工序置信显示保持不变。
- 使用既有inline卡片、折叠details与按钮样式；内容转义，避免注入。不调用模型/线上数据库开展本地测试。

## 红测

实际执行后记录失败与转绿结果。覆盖数据库直取/已批准路线不伪造评分、不同参考真实分数、AI身份、多组成历史方案、无分数及非法分数、非包装兼容、内容转义。
