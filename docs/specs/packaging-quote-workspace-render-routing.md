1. 首页精准/快速按钮只选择路线，不启动 Agent、不展开工作区、不跳精准页；两者互斥，选中样式由 activeQuoteMode 决定，不把快速按钮永久涂成选中态。
2. 快速需求提交先建立服务端实例，再跳入该实例的独立工作区页面。首页卡片再次进入同一工作区，刷新按 URL 实例读取；不在首页继续报价、不误进精准六步、不重复创建实例。复用现有七个命令及后端状态，不复制计算逻辑。

5. 报价分区表格按实际键生成列头，不能只读“项目/值/公式/来源”导致其他字段丢失。所有快照文本安全渲染，无新字体，无灰底消息，无后端协议或数据库更改。
6. 验证包括实际运行渲染器保留嵌套信息、零值和特殊字符；路由/选中态约束、相关旧回归与语法检查。未浏览器验收/未部署必须如实声明。
