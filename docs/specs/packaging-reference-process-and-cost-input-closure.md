# 包装路线命中后的工艺编制与成本输入闭环

2026-10-09；用户本轮授权 Spec、红测及直接实现。依据 local-packaging-downstream-recheck-20261009.md。

## 根因

1. 业务零件适配为 role=None、features=[]，分类退回 machining；统一系统提示、正文要求机械加工，空模型输出再自动添加加工主体/去毛刺及虚拟工时。
2. DA 载荷仅在 note 中；没有作为结构化 lookup 传入，coverage 也只识别另一套库格式。命中后模型可以忽略真实包装工序。
3. 成本输入只构造长宽、克重、数量，未传行上已有的吨价、税因子等；即使已填仍报缺失。缺真实价格的数据则确实不能算，必须区分遗漏读取与主数据缺失。
4. CAD归属、组成、尺寸、材料的缺口仍真实存在。本批禁止用参照件/BOM答案/包围盒估值取消门禁，不能宣称圆盘已全量识别正确。

## 实现契约

- 包装业务 Part 显式 industry=packaging，role 仍只用于装配功能，所有业务单件和组成走包装分支；其他行业保持原机械工艺服务。
- 将 DA lookup 结构化传入：唯一 matched 且非空的真实路线，按原行序确定性建立包装建议骨架，不调用模型改写/删减。保留原序号、operation_code、头/行来源，重复工序不合并。
- 相似、名称命中、草稿均为参考建议，不升级批准。相似件工时不得自动成为本件工时；仅已批准精确编码路线的显式标准秒数可沿用。空工时保持None，不能设置5/8分钟。
- 参考路线不明确/库不可用时使用包装专用提示，不使用机械提示/公差模板；模型为空、报错或返回明显机械加工步骤时明确失败，不能造机械兜底计划。命中但多路线歧义不擅自选一路。
- coverage 与实际建议工序一致，记录采用参考/模型建议与批准状态；保存/返回使用真实 origin。组成逐件检索，保留组成材料、成本参数与来源，不能继承父件的另一种材料价格。
- 历史业务件计划明确标为机械加工/钣金/焊接分类时，保留历史但不得继续汇入包装项目路线计费，提示重做工艺；不得只修新生成的结果却让旧错误照算。
- 材料成本输入传入白名单已填写变量；行/组成参数优先，需求公共税因子可继承。吨价/材料价只认本件参数或需求明确同材料编码，不能拿相似件价格及整盒默认面纸价套灰板。
- 未知材料、尺寸、克重/单位、单价、工时继续有缺口；不写业务库补假值、不修改公式、不启动或部署服务。几何识别、桥接配置、真实价格数据缺失不是本轮程序修复可伪装解决的事项。
- 外购件不编自制路线；面纸克重只允许明确面纸使用，灰板/EVA/纸管/磁铁不得借用。旧红测把双灰板用整盒面纸克重视为通过的口径被本Spec取代，正例改为明确面纸，并新增灰板拒绝负例，不删除计价缺口测试。

## 验证

先跑新增红测证明现状失败。修复后覆盖：真实包装路线原序与重复项、相似路线不拷工时、空/机械模型输出拒绝、包装提示、机械行业不回归、结构化传参、单件及组成成本参数传递、价格隔离、缺价仍缺口。独立读取酒盒CAD事实与真实PG路线再验证工艺，不用答案生成件；完整项目只有全部件工艺/BOM/确认/成本输入满足才可报告通过。
