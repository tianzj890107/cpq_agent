## 目标与边界

圆盘盒原图包含上下两个互斥的内托方案。演示输入应是两份独立 DWG；原图不改，图纸下方的共用运输示意不混入任何方案。分图工具必须拒绝覆盖已有产物，并记录切割范围、保留/丢弃实体数。切割坐标只适用于这张样图，不得当通用识图规则。

包装图纸左侧的「业务零件」与右侧的「排版排模」是两种事实，不得把「各排 2 模」「纸张 860×460mm」「多个件名以 + 或 / 连接」当成一个零件。右侧排模文字须独立保存原文、CAD 实体 ID、排模数及纸张尺寸；解析不出的字段留空，不能猜。方案名是方案元数据，不是 BOM 行。

一件业务零件可由多个不相连的 CAD 片段构成；一个片段也可能只是该件的一层材料。数据模型须保留每片的 CAD ID、图层、矩形及是否已确认，不得仅用并集矩形冒充零件外形；不得因多片而重复计 BOM 数量。排版实例只是用量/版位证据，不是新增业务零件。

## 交互及下游

包装项目第三阶段呈现「3.1 方案与部件」「3.2 排版排模」「3.3 后道加工与组装工艺」；其它行业的既有页签和阶段 ID 不变。包装 3.2 必须能看到排模原文、来源与缺失字段，并能确认/撤销排模数据。现有参数推荐能力保留在第三阶段，不得因更名而丢失。后道工艺也保留装配、检验等工序。

未确认的排模不得进入正式成本；已确认但缺纸张规格、模数、件与排版关系时也不得推算材料用量。DWG 不提供材料单价，不得从图纸/大模型编造价格。模型最多建议件名与片段归属，不能产生 CAD ID 或确认尺寸。

## 验收

1. 上下两个 DWG 可独立解析，方案文字互不串入，原图不被覆盖。
2. 右侧「排 N 模」是排模记录而非业务件；左侧零件仍可读到，非包装样图不受影响。
3. 多片部件可保留每个 CAD 片段信息，数量按业务件计一次；未知归属呈待确认。
4. 包装工作台能展示排模记录与确认状态；未确认不影响现有参数/工艺能力，也不写成本。
