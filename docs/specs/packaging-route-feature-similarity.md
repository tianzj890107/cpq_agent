# 包装工序实际接入零件特征相似度

2026-10-09；本轮用户授权直接实现。本地实现、只读 PG 核对，不部署、不写业务库。

精确编码/名称、名称归一化仍优先；未命中才经认证桥获取包装候选。只允许服务器白名单包装数据源；限 200 条，超限返回明确缺口，不静默截断。候选经物料编码连接材料表，尺寸从完整的 `数字×数字mm` 规格取，材料仅取描述中的材料段，不将排版尺寸/工序当材料。

明确业务编码未命中时禁止静默换成另一编码。未给业务编码时可在包装白名单内找相似件作为参考，包括其他盒型；这不是同盒型的正式绑定，不能说圆盘盒拥有酒盒路线或把几何形状认成相同。无形状/盒型适配证据时仍需按本件编制、审核。

新增纯函数按名称 55%、材料 25%、尺寸 20% 排序。已有方向/编号/件型冲突拒绝；已知材料类型冲突拒绝。材料文本缺失及无可靠尺寸不得补猜，缺失维度记 0 并披露。尺寸可旋转比较，只作适配评分，不继承候选尺寸；强制不使用弱 bbox 尺寸。两条候选差距小于 0.05 或同分返回 ambiguous；最高分至少 0.55。

候选返回真实头行、原顺序及物料证据；相似命中标记 `feature_similarity`、approved=false、逐维分、缺证据项和原件/参照件名称。不把相似评分说成准确率，不继承工时/费率；现有模型基于路线参考编制本件的行为与正式审核门禁保留。

外购短路、库不可用与空库、缺少材料尺寸的原有业务门禁均保留；单件与多组成均调用相同 for_row，组成不会继承父件规格冒充自身。红测覆盖桥接真实接线、方向/材料拒绝、尺寸旋转、近分歧义、缺失/弱尺寸和只读参数化查询。
