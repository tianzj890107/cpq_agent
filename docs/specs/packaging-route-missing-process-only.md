- 有效工艺全齐时3.3不调用模型。不改变手动重新生成入口、权限、正式审核和成本算法，不改3.1/3.2职责划分。

## 当前3.1–3.3口径分析

包装外壳标签分别是方案与部件 / 排版排模 / 后道加工与组装工艺，但通用导航、会话标题与后端状态仍使用整合图纸 / 参数推荐 / 组装工艺。
3.1展示上传整合图纸与2.1零件清单，整合分析动作还连带参数与工艺；3.2展示排模证据并混合产品参数、连接关系与BOM；3.3展示项目路线投影，缺逐件工艺时内部补齐。这是旧机械组装流程与包装流程叠加，不是三个干净独立步骤。
本批只修已获授权的重复生成，不自动重构包装步骤。建议后续明确：3.1选方案与部件组成；3.2排模/纸张/开料与用量；3.3汇总零件工序和必要后道组装，再统一标签及完成状态。
