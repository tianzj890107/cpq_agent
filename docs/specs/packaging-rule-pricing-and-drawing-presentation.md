# 包装报价规则、金额及图纸呈现统一

2026-10-16。本批替代包装第3/4步人工毛利率及手填加价默认入口；历史版本保留。

## 口径

1. 第3/4步复用系统 `md_clm_material_price_rule`，分别读取定价/报价规则；保留规则表达式、来源及命中记录。规则未取到或计算失败不得假装成功，不默认毛利率。包装使用服务端保存的成本和产品，不接受客户端自报成本；保存仍校验销售权限、当前步骤和成本指纹。读取页面不得调用模型或重定价。
2. 金额使用十进制四舍五入到分；销售交接单价先到分再乘数量（47.735 -> 47.74；1000只 -> 47740.00），原始成本保留用于审计。快速报价基准、逐项差异金额、税后单价、偏差金额同步到分。尺寸/比例/数量不按金额截断，金额类费率展示两位但仍保留原参数用于公式追溯。历史报价不在读取时改写。
3. 第5步明细取消新增、删除与保存重算按钮；数量/折扣/税率修改在确认步骤前保存，不能产生未保存的金额。
4. 报价单部件按业务父件聚合，材料组成及工序不增加部件行数；酒盒有28父件时显示28行，不能写死28。工艺按父件分组，跨件组装单列并保留关联。Word必须与页面使用同一份服务端报价。删除指定“本报价为缺口草稿…”整句，不删除底层缺口留痕和正式发布保护。
5. 工序名称兼容step_name/operation_name/title，不能将合法名称丢成“工序10”；展示序号1/2/3，实际工序编码10/20/30及依赖保持不变。历史通用标题优先从连接证据恢复，不猜粘合方式。
6. 排模识别支持CAD文本未写mm的二维纸张尺寸，但必须有排模语境；开料、上机分别提取，不截取三维成品尺寸。旧清单可从本条已保存CAD文字恢复原先漏读的纸张尺寸，不能覆盖人工/明确标注。排模按图纸上到下左到右排列；局部预览只显示本条对应区域，不能每条显示整图；区域不明明确说明，不能冒充原图。近邻尺寸不得跨已定位的排模区域借用；未定位时只列候选，不把无角色近邻当开料，明确开料长/宽标注仍可提供独立证据。估算纸张和CAD标注区别展示。
7. 页面、提示和导出中的展示品牌统一裕同包装；不改真实客户名称、DA来源文件路径和历史数据库记录。
