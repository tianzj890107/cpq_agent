# 排模开料与材料成本分摊

状态：Spec + 红测（已实现）；仅本地，未部署。
红测：`tests/test_packaging_sheet_cut_cost_allocation_red.py`

同一账链：明确排模记录读取开料纸张长宽和各件排出数量，统一算整张材料费用，再按各件所需展开面积占比分摊；保留sheet ID、数量、分摊权重及公式输入。分摊总和必须等于整张费用，不再逐件重复计整张纸，也不再次乘用量。生产纸张数取ceil(max(报价数量×每套件用量/每张排出数量))，校版纸只在整张计一次。不同材料、损耗率或税率不得共用一笔纸张材料账。

无可靠排模的件按展开尺寸加配置余量估算开料。兼容默认长+0、宽+5mm，明确标注余量来源；支持按材料配置，不以候选包围框冒充标注。明确排模缺纸张尺寸/排出数量/关联不完整/多张冲突应报缺口，不能悄悄回退逐件计费。方案只计采用方案，人工关联保留。

CAD尺寸候选记录横竖标注实体与见证点、原图位置。靠近文字不足以认定纸张：不能将零件尺寸、上机尺寸、占用包络直接作为开料尺寸。明确纸张文字（带排模说明）优先；没有角色证据时显示待核实尺寸候选，不自动确认。

3.2显示开料尺寸来源、各件排出数量和分摊依据；候选标注有定位原图按钮。成本面板读取同一材料账，不引入第二套单件引擎。保持原损耗、税率、价格与尺寸门禁；不读取答案表，不部署或写生产数据。
