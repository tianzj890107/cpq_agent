# 包装精简流程与商务报价单（2026-10-16，用户已确认）

仅包装：需求确认及审核→图纸解析与零件工艺→成本测算→报告发布回传。移除process阶段及独立需求审核入口；原内部步骤键保留，display_sub/显示阶段连续编号。报价来源跳过需求重建；旧pending_review跳转合并页。历史数据不删除、不自动改价。

负责项目的工艺工程师/经理可一次确认及审核：pending_confirmation或旧pending_review直接approved，一次持久化，同时记真实确认、审核操作者；重放已批准不重复留痕。不冒用总监身份，报告审核发布权限不改。非包装保留两步。页面只显示产品规格型号、材料结构要求、数量交期附件和意见；客户、信用与商务字段仍保存但不展示。

包装不运行排模/名称关联/新增组装模型，不依赖参数/组装确认；BOM与项目路线仅汇总完整零件已有工艺。新增成本忽略排模输入，使用零件尺寸加余量，已有粘合/包盒/组装保留。旧组装结果保留，但不再追加计费；旧成本读取不重算，重算后显式采用新计算政策。图纸完成后提供直接发送报价人员任务的动作，不强迫工艺人员写成本。

财务显示统一报价人员，保留finance_mgr/finance_manager与FI1、SSO及权限，不扩权给销售。历史审计不改。

最终包装报价预览与Word沿用现有亿纬中文版综合单价商务结构：单号/日期/客户/有效期/币种，产品名称/型号/成品规格/单位/数量/单价/总价，税额与含税合计，交期/付款/联系人。内部BOM/工艺/成本/利润/公式/来源不对客输出，原内部数据仍可审计。裕同签约信息仅用已保存配置，不拷贝亿纬主体地址或示例联系人。金额只取已保存报价，保持两位小数；保留草稿/演示标识及真实导出门禁，不增BPM审批。
