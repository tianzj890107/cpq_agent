# 包装第3阶段：排版排模与新增组装工艺

日期：2026-10-13。取代包装三页签展示；非包装保持既有三个页签。

## 页面与操作

- 包装仅显示3.1排版排模、3.2组装工艺。内部params/process视图沿用；旧drawings视图
  进入排模页，旧process链接进入组装页。方案选择并入排模顶部，单方案无需独立采用步骤。
- 零件/组成/候选仍在2.1；排模页显示纸张开料、每张排出数量、关联多个零件、无排模开料
  及余量。首次进入下一步时准备缺失开料输入，纯读不写库，不重跑模型。
- 排模选择采用紧凑复选列表，长名称换行，复选框不受全局input的100%宽度影响；每行
  纸张与数量用专属紧凑网格。关联区域默认折叠、限高滚动，保存关联与折叠入口同一行。
- 组装页只展示跨零件新增工序及其零件绑定、内容、设备、工时/来源。不再次展开制造件
  工序。允许多选整件作为关联对象，修改后实际保存；来源/说明/文本转义保留。
- 入口按钮先发用户消息，再播进度与结果，沿用现有工具卡/按钮样式。采用组装工艺后按
  原发送财务流程继续。不增加一键贯通按钮，不新增人工确认关卡。

## 数据与成本

- 整件制造工艺仍保存于原零件工艺记录。integration.process仅保存assembly_delta/1新增
  组装方案，不能把完整项目路线复制进去。新增方案由一次模型调用结合当前方案的零件、
  材料、尺寸及已生成工艺编制，禁止返回单件开料/印刷/覆膜/模切等制造工序。
- 每道新增工序必须绑定当前方案至少两个不同整件ID；不允许子组成ID、不存在ID、其他
  方案ID或重复ID。保留人工编辑的零件绑定。不得按单纯“粘合”名称把所有单件粘合取来。
- 没有跨零件装配需求时可保存明确“无新增工序”的分析结论；无结果不能冒充已分析。
  POC模型不可用沿用披露估算原则，产生绑定当前零件的基础装配建议并披露降级原因，
  不冒充成功AI调用。相同输入可复用新增组装结果，零件/工艺/方案变化则失效。
- 完整项目路线=整件制造工序+新增组装工序。新增工序只追加一次，计费按每套成品用量1，
  不乘关联零件数量；关联字段进入操作实例元数据/指纹，路线变更让成本过期。
  组装页隐藏制造列表不删除制造记录、不漏材料或工序成本。
- 流程投影按行业生成两个步骤，读取真实整件工艺记录，修复空记录导致已完成仍未完成。
  完成条件为排模/开料已齐、有效新增组装方案、所需整件工艺有效及原采用状态。
  旧整条路线投影保持历史但不是当前新增组装方案；原按钮重新生成可更新。
