# 包装工艺以业务零件为分析单位

日期：2026-10-13。取代 `packaging-route-missing-process-only` 的逐组成生成口径，以及
`packaging-three-stage-workspace` 中按组成分别展示工艺的口径。

## 业务要求

知识库与权威 BOM 的工艺归属是业务零件。一个零件有多个 CAD 闭合图形、多个物理组成，
不意味着应生成多份工艺。几何组成继续保留自己的图元、材料、尺寸、用量和开料材料账。

1. 单件入口与批量补齐均以完整零件名称/编码查找参考工艺，一件只生成一次工艺方案。
   输入带全部组成的名称、尺寸、材料、数量作为上下文；不能将组成名称替代零件名称检索，
   不分别调用模型生成组成方案，也不将它们机械串接成整件方案。
2. 多组成零件没有整体展开尺寸时允许使用组成尺寸上下文推荐工艺；不将各部分并集包围框
   冒充整体尺寸，不丢失材料差异或缺项信息。不改变材料/开料成本的组成级数据。
3. 当前工艺记录标识 `process_scope=business_part/1`，方案属于父业务件，`sections=[]`。
   项目路线只展开父件工艺，计费用父件每套用量，不再次乘几何组成个数。
   同名但实际不同的两道工序仍保留，不靠名称去重；推荐来源、工时、依赖、计费参数保持。
4. 旧的分组成工艺或携带组成工序的合并方案不冒充有效整件工艺。保留历史记录，读侧显示
   待按整件重新生成；原有一键推荐/3.3补齐只重算这些件，其余有效整件方案继续复用。
   无组成工序的历史整件方案可兼容复用。不批量改写项目、历史版本或线上业务数据。
5. 零件内工艺面板、独立工艺页及3.3均展示一零件一套工序，旧结果不能按组成继续展示为
   当前推荐。3.1保留多组成展示，3.2保留组成级开料/共排，不改变其几何与材料账。
6. 工艺口径改变使旧项目路线/成本指纹过期，沿用原点击流程重新生成路线和成本。
   一件的工序不能因有两个组成而重复计两遍；材料仍按各组成实际材料用量计算。
