# 单件尺寸标注完整显示

精确图元绑定可以限制形状成员，但不得同时删除标注归属证据。标注引用、标注分量和形状定义点包络应独立保留。候选预览、已绑定件、组成部分使用一致口径；不得混入邻件或编造尺寸。

默认100%表示包含形状、尺寸线及完整文字的适应窗口。文字的字高、字数、旋转占据范围必须进入展示包络，不能只算文字插入点。展示包络仅用于预览，不用于成本或零件尺寸计算。

缺少CAD标注时明确保留缺失状态，不以虚构尺寸补齐。已有CAD尺寸不得因精确绑定而消失。
