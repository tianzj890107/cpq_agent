# 项目分页与工作台渐进加载

2026-10-08。本地直接实现。

- 技术工艺我的/全部项目按服务端页读取，页号、搜索、归档和权限均参与查询；当前页也只读取轻量元数据，不 build_card、不为展示读取成本/BOM/会话/IR 明细，未知结论不伪造。既有权限判定所需交接/领取依据仍保留，不为速度放宽 ACL。分页采用更新时间降序、项目 ID 升序的稳定顺序，权限先于分页；旧无页参数列表接口兼容，未分页历史消费者另行升级。
- 首页项目先显示，再异步补待办/工作流；页请求按 scope/page/query 区分，迟到旧页不得覆盖当前页。切换筛选回第一页。
- 卡片已有阶段目标时直接跳页，不等四个详情接口；无目标时先跳工作台，再恢复阶段。
- 第 2 步已存零件优先显示，流程状态、角色映射/BOM及兼容补算不阻塞主页面；后台补算去重，切换项目后旧结果不得覆盖新项目。
- 第 3 步已保存整合结果先渲染，不等待零件成本逐件读取/会话回放；后台失败仅影响对应区域。
- 不改权限/审核/成本门禁，不重解析已有图纸、不触发 LLM 推荐作为加载条件；无上线授权。

- 相关权限/首页/渐进加载等 146 项通过；后续补项目切换保护后，相关 70 项通过。两组重叠，不合计；最新新增模块 9 项单独复跑通过。前端模块及首页内联脚本语法、diff 检查通过。
- 首页一次只读 6 个项目的元数据。无页参数旧接口保持原列表形状，历史抽屉等旧消费者仍可能使用重接口；未宣称所有消费者已经轻量化。财务/销售 ACL 原有必要证据读取仍保留。
- 缺完整阶段信息的卡片立即进入工作台，再恢复该项目的阶段；不在首页扫描所有项目来得到详细进度。第 2 步后台补算仅复用既有兼容行为，有权限及去重限制，不触发图纸重解析。
- 本地实现，未全仓回归、未提交/推送/部署、未启动服务或浏览器验收；没有线上耗时复测，不能宣称已达到某个毫秒指标。
