# 报价第3—6步进入即计算

包装与原行业共用进入执行入口：先恢复上下文、成功标记开工，再计算或生成当前步骤。第3/4步调用现有系统库规则接口，保存后渲染；第5步沿用已存规则生成方案，包装保存金额；第6步沿用既有报价内容生成文档，不另算金额。

刷新/重开卡片：恢复已有有效结果；当前步骤已开工但结果缺失时自动补执行一次。禁止重建项目、回退工艺、浏览历史步骤触发计算、只读/已完成/待交接卡片写入。相同会话步骤并发合并，失败不循环重试，当前步骤提供重试入口。保存的有效结果不得因刷新重复计算覆盖。

上游规则缺失/计算失败应明确失败，不虚构利润，不绕过门禁。旧行业仍使用现有规则和文档工具。本批不修改公式、规则数据、成本及行业筛选策略。

包装规则计算的产品上下文必须包含产品系列、产品型号、成品编码；型号使用回传包的既有盒型编码，与工作台投影一致，避免规则明确引用“产品型号”但系统仅传“成品编码”。
