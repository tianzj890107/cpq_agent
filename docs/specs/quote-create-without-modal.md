# 新建报价直接进入第1步

日期：2026-10-29。范围：普通六步报价的新建入口。

点击首页“新建报价”后，无需填写项目名称、客户名称或需求，无需信息确认弹框，直接创建新的报价会话并进入第1步。首页发送已有需求时同样不弹框，完整保留正文、附件引用和所选行业。项目编码自动生成；未知客户保持空值，项目名称允许使用中性临时名称，不得冒充客户提供的信息。进入后沿用第1步补充资料和后续正常门禁，不提前报价、不伪造成本。

新建必须清除上一项目的元数据和会话定位，不能打开或覆盖历史项目。双击不得重复创建。附件解析中或上传失败时显示现有错误，不创建半成品。创建失败需可见提示并允许重试。配置、规则、技术工艺、经营分析及显式快速报价入口保持各自行为。

## 验收

- 空白新建一次点击进入第1步；不出现截图中的信息确认框。
- 带客户原文、附件和包装行业提交，不要求额外填写名称；需求和附件不丢失。
- 先打开历史项目再新建，获得不同会话，旧项目及数据不变。
- 双击仅创建一条；接口失败可重试；刷新可恢复新会话。
- 不能把自动名称说成用户在弹框填写的权威值；项目及客户资料可在既有第1步补齐。
- 隔离浏览器验收使用临时数据库，不操作线上历史数据。

首轮自动化红测执行真实 requestNavigate 函数，分别覆盖空白入口和客户原文入口；预期失败点为仍显示 projectModal，且没有进入报价页。完整实现还需增加隔离浏览器会话创建、附件、双击及失败重试验收。

## 行业预填（用户明确授权直接实现，10-29）

四个可选行业沿用服务端唯一注册表；服务端在表单目录下发可编辑推荐默认值。新会话第1步立即显示基本信息、目的地、产品需求草稿、技术需求草稿、付款里程碑和物流推荐。包装、半导体、电池、电器分别给不同的产品描述、应用和运输建议；付款推荐为预付款30%、发货前尾款70%，页面明确提醒可修改、待核对。客户、地址、成品编码、价格、成本及未提供的尺寸不虚构。推荐产品行不是数据库匹配或选用结果。

仅新会话初始化时填入；恢复历史不填，已有值不覆盖。更换行业不自动覆盖用户编辑。推荐值随既有第1步快照保存与恢复；切换行业后可新建使用对应推荐。
