# 报价与技术工艺智能体工作台壳一致性 Spec

状态：TDD Red，等待 DeepSeek 实现。

## 目标

报价单智能体与技术工艺智能体属于同一套 CPQ 产品。技术工艺统一工作台必须沿用报价单智能体的页面骨架、信息层级和操作区布局，而不是保留另一套带间距、圆角卡片和独立底栏的设计。

本需求同时补齐报价单智能体左上角 Logo 返回统一主页的行为。

## 1. 报价单智能体 Logo 返回主页

- `确认需求解析结果.html` 最左上角 `.nav-logo` 必须是可访问的链接或具有等价键盘行为的按钮；
- 点击后返回 `/报价首页.html?assistant=quote`，进入统一主页的报价模式；
- 不得把 Logo 点击绑定为重置会话，不得删除下方原有主页按钮；
- Logo 必须保留现有图标、尺寸和视觉样式。

## 2. 技术工艺工作台使用报价智能体三列骨架

桌面端从左到右固定为：

1. 56px 左侧导航栏；
2. 技术工艺 Agent 常驻会话区；
3. 技术工艺步骤工作区。

左侧导航栏的结构与报价智能体一致，至少包含：

- 顶部可点击 Logo，返回 `/报价首页.html?assistant=tech`；
- 新对话；
- 历史记录；
- 返回统一主页；
- 底部消息、设置和账户入口。

应复用现有 `cpqMsg`、`cpqAuth` 以及技术工艺会话能力，不复制后端接口，不把导航做成仅有图标但无行为的静态摆设。

## 3. 顶部信息层级与报价智能体一致

技术工艺会话列顶部必须显示：

- 标题 `技术工艺智能体`；
- `AI` 徽标；
- 真实连接状态：初始可显示“连接中…”，Agent meta 请求成功后显示“已连接”，失败显示“未连接”；不得硬编码永远已连接。

技术工艺右侧工作区顶部必须显示：

- `当前项目`；
- 当前项目名称或项目号，未绑定时明确显示“未绑定项目”；
- 流程名称 `技术工艺流程`；
- 当前真实模型，例如 `· qwen3.5-plus`。模型名来自现有 Agent meta/设置数据，不写死具体模型。

标题、连接状态、项目、流程和模型的相对位置、字号、边框应对齐 `确认需求解析结果.html` 中 `.chat-header` 与 `.project-header` 的结构。技术工艺业务文案使用“技术工艺”，不得错误显示成“报价单智能体”或“报价测算流程”。

## 4. 右侧工作区取消独立卡片感

- 技术工艺左右区域直接贴合三列骨架，不保留当前 `14px` 分栏 gap 和外围 padding；
- `.tech-workspace-pane` 不使用圆角、悬浮阴影或四周卡片边框；
- 允许使用与报价智能体一致的细分隔线；
- 右侧步骤内容仍由既有同源 iframe 承载，九阶段注册、URL 恢复、同源校验和项目会话保持逻辑不变；
- 不得通过删除进度、项目标题或业务内容来获得视觉一致性。

## 5. 上一步、下一步和本步操作只属于右侧卡片

`.tech-workbench-bottom` 必须移动到 `.tech-workspace-pane` 内部，位于步骤内容之后；不得继续作为跨越整个页面宽度的全局 footer。

底栏布局：

- 左侧操作组：`上一步`、当前步骤提示、本步次要操作、本步主操作、子页面板；
- 右侧操作组：只能放 `下一步`；
- `下一步` 必须是底栏最右侧唯一按钮；
- 不得在左侧会话列或 56px 导航栏下方出现上一步/下一步；
- 本步主/次操作仍代理子页面真实按钮，不复制或绕过其业务逻辑和禁用状态。

响应式窄屏可以纵向排列三部分，但导航、会话、工作区和右侧底栏的归属关系不能改变。

## 修改范围

允许修改：

- `确认需求解析结果.html`：仅 Logo 返回主页行为；
- `tech_app/frontend/tech-workbench.html`；
- `tech_app/frontend/tech-workbench.css`；
- `tech_app/frontend/tech-workbench.js`；
- `tech_app/frontend/agent-chat.js`：仅连接状态、模型信息及现有会话导航能力对接；
- 必要时调整 `agent-chat.css` 中与统一壳直接冲突的样式。

## 禁止事项

- 不修改后端 API、数据库、权限、审批、成本公式和任务流；
- 不新增第二套 Agent 会话，不因切换 stage 重建左侧会话；
- 不改变九阶段 id、顺序、页面映射、URL 参数或 postMessage 安全校验；
- 不删除历史会话、项目、任务、附件或设置；
- 不大范围重写各 iframe 子页面；
- 不执行 push、MR、merge、tag、Release、部署或服务重启。

## 验收标准

1. 报价单智能体左上 Logo 点击进入统一主页报价模式。
2. 技术工艺桌面端具有 56px 导航、会话、右侧工作区三列，导航能力与报价智能体对齐。
3. 会话顶部真实显示“技术工艺智能体 / AI / 连接状态”。
4. 工作区顶部真实显示“当前项目 / 技术工艺流程 / 当前模型”。
5. 技术工作区无外围间距、非零圆角和悬浮阴影，整体分隔风格与报价智能体一致。
6. 上一步、下一步和本步操作底栏只在右侧工作区内；左侧为上一步及本步操作，最右只有下一步。
7. 连接状态、项目和模型信息来自现有运行数据，不硬编码成功状态或模型名称。
8. 原有会话持久性、九阶段导航、iframe 安全边界和业务按钮代理保持不变。
9. 新增 Red 测试转绿，已有测试继续通过，`git diff --check` 通过。
