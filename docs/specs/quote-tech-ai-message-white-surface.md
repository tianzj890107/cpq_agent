# 报价与技术工艺 Agent AI 消息白底统一 Spec

状态：Spec + 红测（已实现）
红测：`tests/test_quote_tech_ai_message_white_surface_red.py`

## 背景与目标

技术工艺 Agent 的普通 AI 消息采用“圆形 AI 头像 + 白色会话底上的正文”，没有浅灰气泡卡片；
报价 Agent 的 `.message-ai` 仍使用 `--bg-secondary` 浅灰背景、描边和左下气泡尾部。两个 Agent
因此呈现为不同的聊天产品。

本批以技术工艺 Agent 为视觉基准：两侧普通 AI 消息统一为白底正文。仅统一普通 AI 消息容器，
不把代码块、工具调用、确认卡、推荐结果、警告和错误卡片强制改成白色。

## 产品契约

- 报价 `.message-ai` 背景必须通过 `var(--bg-page)` 使用系统白色表面；
- 报价普通 AI 消息不再显示灰色气泡描边，也不再使用左下角气泡尾部；
- 技术 `.oc-amsg` / `.oc-abody` / `.oc-atxt` 继续保持透明或白色普通消息表面，不得增加灰色、
  品牌色或渐变背景；
- AI 正文保持深色，仍位于会话左侧；
- 报价侧既有 AI 标签、技术侧既有 AI 头像均保留，本批不要求重构两边消息 DOM；
- 用户主色蓝气泡不受影响。

## 范围

允许 DeepSeek 修改：

- `确认需求解析结果.html` 中 `.message-ai` 普通消息容器样式；
- 必要时调整相关静态资源缓存版本；
- 当周 changelog。

技术侧已经是目标基准，除非修复明确的白底回归，不应改动 `agent-chat.css` 的普通 AI 消息结构。

## 禁止事项

- 不修改 `.message-user` / `.oc-ubub` 用户消息主色气泡；
- 不删除技术侧 AI 头像，不改报价侧 AI 标签 DOM；
- 不修改代码块、工具卡、任务卡、确认卡、候选产品表、错误和语义状态卡的背景；
- 不修改消息生成、Markdown、流式输出、接口、会话存储或后端；
- 不通过全局替换 `--bg-secondary` 实现；
- 不修改本 Spec 或 Red 测试以迁就实现；
- 不执行提交、推送、MR、merge、tag、Release、部署或服务重启。

## 验收标准

1. 报价普通 AI 消息为系统白底，不再是浅灰气泡。
2. 报价普通 AI 消息没有卡片描边和左下气泡尾部。
3. 技术普通 AI 消息仍为白底/透明正文，没有灰底、主色底或渐变。
4. 两边 AI 正文保持深色并左对齐。
5. 用户蓝色气泡、工具卡、代码块和业务结果卡保持原样。
6. 新增 Red 测试转绿，用户消息和品牌色测试继续通过。
