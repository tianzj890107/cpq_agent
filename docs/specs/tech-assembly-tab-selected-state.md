# 组装与整合三流程页签选中态 Spec

## 范围

技术工艺“工艺方案/组装整合”页面右侧卡片顶部的三个页签：

- 整合图纸：`[data-ai-tab="drawings"]`
- 参数推荐：`[data-ai-tab="params"]`
- 组装工艺：`[data-ai-tab="process"]`

只修改页签视觉，不改变 `aiTab`、点击切换、完成状态、生成流程或后端逻辑。

## 视觉契约

- 未选中：保持当前中性文字和细边框，不使用深色填充。
- 普通 hover：允许使用柔和浅蓝背景和品牌蓝文字，但不能冒充深蓝填充的选中态。
- 选中 `.active`：白色背景、品牌蓝文字、1px 品牌蓝或品牌浅蓝边框、现有胶囊圆角和加粗文字。
- 选中态在 hover/focus-visible 时仍保持白底蓝字蓝边框，不得变成深蓝底白字。
- 应提供清晰的 `focus-visible` 轮廓，键盘用户能够识别当前位置。
- 不使用 `background:var(--oc-accent)`、`#0067D1` 深色填充或 `color:#fff` 表达 active。

## 验收

1. 三个页签继续由 `aiRender()` 保证恰好一个 `.active`。
2. 当前页签始终白底蓝字蓝边框。
3. 切换页签时选中样式同步切换。
4. hover、focus 不把选中项变成深色。
5. 不影响页面动作按钮的描边/填充、disabled/busy 状态。
