# 文件资产统一、按用途解析

2026-10-15。仅统一报价/工艺的附件资产、能力配置与上传反馈，不新增CAD/3D/OCR解析器，不改变历史文件。

## 规则

- 前后端读同一份格式注册表。通用报价/工艺会话和首页资料上传接受相同资产范围：DWG/DXF、已接收的3D格式、PDF/Office文档、常用图片、文本/结构化文本。只收白名单，名称/大小/原件校验保留。
- 业务用途区分：资料接收、需求提取、二维图纸解析、3D资料接收、3D实体导入、快速报价匹配。专用导入不扩为任意附件，例如3D实体导入仅STEP/STP；工作簿导入仍限原表格格式。
- 每种文件按用途标 `direct` / `converted` / `save_only`，分别显示可直接解析/需转换后解析/仅保存并随项目交接。DWG是否实际可转仍由现有运行时探测决定，静态表不保证转换器存在。
- 报价图片不冒充OCR；DOC/XLS仅存档并提示另存DOCX/XLSX；PDF文本提取与二维PDF图纸需人工转图分别披露；包装以DWG/DXF为主，不诱导3D建模。
- 通用附件单文件16MiB，服务端也限制；非法后缀、空文件、超限在读全文/持久化前拒绝。既有大文件读回/历史不删除。专用工作簿入口保留独立更严格校验。
- 文件已保存但不能解析不是上传失败。保留原件与小引用，不调用不适用解析器，不清空快速报价已有参数，不将二进制送模型。
- 原件在报价接收并交接工艺，不要求重复上传；混合资料优先取CAD作图纸，文档不能伪装成原始CAD。独立工艺可以仅收资料建草稿，解析步骤再补图，不伪造占位图。
- 混合资料的主图选择同时查看主文件、多文件及补充附件，不依赖选择顺序；历史非新白名单附件保持鉴权读回及SHA校验，不允许借历史兼容绕过新上传白名单。
- 复用现有按钮/文件卡片，添加统一弱提示与单文件能力说明；页面和动态插入的输入框都应用。策略加载失败明确提示，不偷偷宣称全部能解析。

## 验收

实际红测后实现：公共注册表与用途筛选、两端限额与白名单、图片/旧Office仅存档、STEP只交接不在快速匹配中解析、混合资料CAD优先、动态输入与错误提示、原件交接回归。再运行相关保护网、语法、双推精确提交、34健康/能力/真实样本隔离验证；不改现有用户项目做破坏性验收。
